概要

推薦の履歴は noisy で不規則だが、候補は多い。ReST は user history を重く一度処理し、candidate interaction を軽く反復する。

問題設定

DLRM-like feature branch が強いと、sequence representation を使わずに loss を下げられる。層や長さを増やしても sequence branch の勾配が小さければ scaling は飽和する。

核心

論文に書かれていること

ReST は dual-gated attention、rotary positional/temporal embedding、stabilized residual normalization、training-only auxiliary objective を持つ sequence encoder と、heavy encoder/light cross decoder を提案する。Abstract は 50 ms P99 内で online AUC +1.31%、主要 revenue metric +11.93% を報告する。

読書メモ

『長い Transformer が弱い』のではなく、hybrid の非系列 branch が shortcut になれば sequence encoder に学習信号が届かない、という診断が中心である。

なぜ効きそうか

読書メモ — 著者による因果の立証ではありません。

読書メモ（推論）。補助 sequence loss は shortcut と独立した誤差信号を作る。これは accuracy を保証せず、候補 feature を外した controlled ablation で確認すべき仮説である。

根拠

Abstract は public/industrial benchmark と一週間の広告 platform A/B を報告する。著者の production 数値は強い実務証拠だが、feature、traffic、objective を固定した外部比較ではない。

実行可能な理解

uv run papers/rest-sequence-ranking/run.py は shortcut fusion と補助損失の合成 gradient share を比較する。Transformer を学習しない。

結果

固定した合成勾配の会計。ReST の attention、16k 系列、online A/B は再現しない。

補助損失を足した側で sequence branch の share を大きく置く toy である。実 AUC や 16k token scaling の証明ではない。

検証できたこと

メカニズムは PARTIAL。shortcut があると系列側の寄与が小さくなり、直接の損失を加える理由があることを可視化した。

検証していないこと

DGA、RoTE、projection-free KV、shared-prefix serving、online A/B、P99 は未検証である。

実装

数値は説明用に固定した CPU toy である。学習済みモデルの代用品として解釈しない。
