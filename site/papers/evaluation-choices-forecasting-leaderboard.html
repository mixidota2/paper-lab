問いモデル / 手法集計を分割すると基準手法の順位が落ちる絶対値を取る前なら誤差が相殺する根拠小実験限界

概要

市場全体では2/19位だった本番の基準手法が、買い手別では23/25位になる。対象はサービス市場の取引額GTVで、店舗小売の売上ではない。M5での再評価もあり、手法比較の設計に関わる論文。

問題設定

大きな集計では正負の予測誤差が相殺する。個別系列ではその誤差が残り、間欠的な需要も増える。本番の基準は前年同月を直近の勢いで調整するseasonal naive with driftで、比較にはN-HiTSやChronos T5-Largeなどを含む。

核心

著者の主張 · 論文に書かれていること

データや予測値に加え、評価単位・誤差の集約・指標の選択が順位を決める。同じ手法集合と評価起点に絞った比較でも順位の逆転が残る。

解釈・批評 · 読書メモ

TSFMとGBDTの比較を始める前に、誰の誤差を一単位として数えるかを固定したい。全体の売上計画に適した評価と、店舗・商品ごとの補充判断に適した評価は一致するとは限らない。

モデル / 手法

誤差を足す順番を変える

Table 3とFigure 1が評価粒度の中心図。集計数kを増やすと平滑な市場系列から変動の大きい小集団へ移る。表の中央値WAPE順位はk = 1, 5, 25, 125, 625で2, 14, 14, 16, 16位。これは19手法内の順位であり、25手法による買い手別順位を同じ曲線へ継ぎ足さない。

人工例は4買い手すべての実績を100とする。Aの誤差は+40, −40, +40, −40、Bはすべて+10。市場全体ならAの誤差は相殺され0%、個別に絶対誤差を足すと40%。Bはどちらも10%となる。同じ2組でも分け方によってAの相殺の有無が変わる。

Table 6の回収率はG = (E_baseline − E_served) / (E_baseline − E_oracle)。表示されたRMSSEの0.946、0.724、0.540からは約54.68%となる。論文の54.6%との差は、丸め済み値からの再計算として残す。oracleは事後に最良手法を選ぶ上限で、本番で実装できる選択器ではない。

区間予測のTable 5は193,067レコードを評価する。間欠需要での相関0.02は、25手法間の限られた推定である。全需要・全期間で点予測と区間予測が独立だと証明した数値ではない。

なぜ効きそうか

解釈・推論

解釈：絶対値を取る前に誤差を足すと相殺が起きるため、集計後の誤差が小さくても個別の予測は良いとは限らない。|Σeᵢ| ≤ Σ|eᵢ|という性質を最小実験で確認する。区間予測には幅と被覆率が関わり、点予測の順位から一意には決まらない。

根拠

一次資料Tables 1・3・5–7 の著者報告。

比較 値 注意
市場集計 → 買い手別 2/19位 → 23/25位 Table 1は指標・起点・手法数も異なる
選択ルールの改善余地回収 54.6% 過去の起点だけで選ぶ、RMSSE基準
M5の同様の回収率 64.7% 店舗×商品で再評価
点予測と区間予測の順位相関 0.02 間欠需要、25手法間の相関

主要な買い手別評価は1,887系列・67か月、8起点・11,516ブロック。Table 3では共通の19手法を使い、事前データでサイズ順に5,779買い手を分組する。1組から625組への分割で基準手法の中央値WAPE順位は2→16位になる。Table 1だけから集計単独の効果と断定せず、共通条件の再評価も読む。
