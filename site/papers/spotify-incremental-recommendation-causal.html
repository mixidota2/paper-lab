概要

Spotify は自然に再生される推薦を二つの閾値で除外する。2週間の A/B で表示は7.1%減り、推薦コンテンツの消費は−0.37%で有意差なし。計測窓が異なる二つの予測値を引き算しない設計が要点になる。

問題設定

二つのラベルは別物である。推薦ありでは表示直後の短い反応を拾う一方、holdback では他の経路からの自然な発見も拾うために2日間待つので、名前が同じ再生確率でも引き算の意味は変わる。

§3 は、backend の配信と client の表示に約30%の差があるとも記す。計測経路も違う。無作為割当であっても、この差は残る。

核心

著者の主張 · 論文に書かれていること

既存の無作為 holdback データを共有 trunk と専用 head の学習に再利用する。推薦後の再生確率が高く、自然再生確率が低い組だけに推薦する。新しい収集基盤を要しない。

解釈・批評 · 読書メモ

CATE の推定値ではない。異なる計測窓から得た二つのスコアを意思決定に使い、同じモデルと学習データの下で表示方策だけを変えた A/B によって、表示の削減と消費への影響を確かめた事例と読む。

モデル / 手法

共有表現へ二つの観測を流す

Deep Twin Network は既存の multi-task shared-trunk model に holdback head を加え、各群の binary cross-entropy を群内平均して足す（Fig. 3、Eq. 4）。

更新する部分 学習データ
treated head 推薦ありの群 D₁
holdback head 推薦を止めた群 D₀
shared trunk 両群

割当確率は既知。propensity head は付けない。

二つの条件を両方満たす組へ表示する

Eq. 5:

π(x) = 1[p̂₁(x) ≥ θ₁] · 1[p̂₀(x) ≤ θ₀]

θ₀を上げるほど表示条件は緩み、θ₀=1で単一閾値へ戻る。原文 §4.2 の説明文には、この方向を逆に述べる箇所があるため、本 Lab の図と実験は式の不等号に従う。

なぜ効きそうか

解釈・推論

本 Lab の解釈: 推薦なしでも再生しそうな組を外せば、その枠を別の推薦へ回せる。ただし低い自然再生スコアは、個々のユーザーに推薦が必要だと証明しない。共有表現が嗜好と推薦への反応を捉えるという説明も、Fig. 4 の校正改善だけから一意に確定するものではない。

根拠

一次資料の著者報告を示す。

Table 1 は Treatment-Causal と Treatment-Model の比較である。比較軸は表示方策。モデルと学習データを固定し、二重閾値の追加を比べる。従来モデル Control との比較値ではない。対象は Spotify Home の数百万人、期間は2週間。

指標 相対差 95% CI
推薦表示 −7.1% [−7.2%, −6.9%]
推薦コンテンツ消費 −0.37% [−0.86%, +0.21%]

消費の有意差なしは、損失ゼロや非劣性の証明と同義ではない。掲載値だけでは非劣性マージンを確認できない。著者は残る約93%を incremental と解釈するが、集約 A/B から個別表示の因果効果を直接識別した数字ではない。

Fig. 4 は treated head の校正曲線が従来モデルより対角線に近いと示す。holdback head の高確率側には小標本によるずれがあると著者は説明する。図から誤差指標の数値は作らない。

実行可能な理解

uv run papers/spotify-incremental-recommendation-causal/run.py

入力は4組。ユーザー・コンテンツ組に固定の予測値と潜在結果を与え、θ₁=0.4のままθ₀を0から1まで動かすと、単一閾値で残る組のうち自然再生スコアの高い組がどの順に外れるかを追える。

学習はしない。短期と長期の差が負でも、同一窓の真の追加効果が正となる反例を含めた。
