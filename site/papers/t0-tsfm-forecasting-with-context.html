同じ予測モデルに、未来の予定を渡す価値はあるか

t0-alphaの同一checkpointでcovariateを入切すると、fev-benchの既知未来30課題でskill 36.7→43.0、+6.3ポイント。19課題は改善し11課題は悪化。販促・欠品条件でTSFMとGBDTを比較した結論ではない。

このLabを読む

問いモデル / 手法cutoffの先に渡してよい情報を区別するcovariateの有無だけを変えて同じcheckpointを読む同一checkpointでも全課題は改善しない根拠小実験限界

概要

主な読みどころはモデル間の順位より、同一checkpointに情報を追加する比較である。+6.3はskillのpercentage pointで、MAEが6.3%改善したという意味ではない。モデルの深掘りは主にt0-alphaで、t0-betaの256Mや21分位点へ混ぜない。

問題設定

単変量モデルは販促日や休業日を知らない。情報を渡せるモデルでも、無関係な変数を無視できなければ逆効果になる。また「既知未来」として評価時に渡した情報が、発注時点でも本当に分かっていたかを確認する必要がある。将来の実天気や実売上を予定として渡せば漏洩になる。

核心

著者の主張 · 論文に書かれていること

時間軸と変数軸のattentionを交互に使い、target履歴・過去covariate・既知未来covariateから分位点を予測する。102Mのt0-alphaと256Mのt0-betaを公開し、事前学習にcovariateとtargetの依存を持つ人工系列を混ぜる。

解釈・批評 · 読書メモ

ApolloPFNと同じく外生変数を扱えるTSFMの証拠が増えた。ただしAccuracy Is Not Serviceが問う在庫・注文充足への変換は残る。Chronos-2は変数軸attentionやcovariate ablationの近い比較対象。小売の販促有無、欠品による売上打切り、GBDTと同じ情報集合での比較を揃えて初めて導入判断へ進める。

モデル / 手法

alphaの24層は「時間2、変数1」を繰り返す

patchは32時点。t0-alphaはhidden 512、8 head、時間attention 16層と変数attention 8層を持ち、RMSNorm・SwiGLU・QK normを使う。target yと過去変数xの時間方向はcausal、既知未来zは1:T+Hを双方向に読む。変数方向ではy/xがzを読める一方、zはy/xを読まない。逆参照を許すと、zの時間attentionを経由して未来targetが過去へ戻る。

正規化にもcutoffを守らせる

y/xは時点ごとのcausal mean/stdで標準化してarcsinhを取る。未来targetの教師はcutoff T時点の統計で固定する。zだけは既知なので全1:T+Hから統計を取れる。欠測はmaskし、統計とlossから外す。static covariateやtext metadataを直接読む機能は本報告の対象外。

alphaのnative分位点は0.1/0.25/0.5/0.75/0.9。最小分位点を直接予測し、残りはsoftplusで正の差分を足す。weighted pinball lossの重みは0.175/0.2/0.25/0.2/0.175。betaは21分位点、0.01–0.99であり仕様が違う。

情報の価値とforecastの価値を分ける

同じcheckpointの入切比較はcovariate経路の寄与を捉えるが、その予定が正確か、欠品した売上が需要を表すかは別の問題。さらに出力は各時点のmarginal quantileで、時間・商品間のjoint distributionは持たない。補充費用を計算するには追加の意思決定検証が要る。

本文のalpha通常推論はnative範囲外のquantileを端点に留め、IQF tail外挿を別途評価する。確認時の公式READMEは外挿対応を説明しているので、論文v1と現行APIを同一仕様と決めつけない。

なぜ効きそうか

解釈・推論

covariateがtargetを動かす人工系列を事前学習へ加え、変数間attentionでその関係を読めるようにする。未来の予定を読む経路には価値があるが、ノイズを無視できる保証はない。11/30課題の悪化やM5の小さい差は、covariate対応という機能名だけでは選定できないことを示す。

根拠

一次資料PDF §5.1.2 / Tables 4–5 / §6 の著者報告。

t0-alpha・同一checkpoint covariateなし→あり 95% bootstrap CI / task
既知未来30課題 skill 36.7→43.0、+6.3 pp [+2.2,+10.9]、19/30改善
過去のみ12課題 32.9→35.6、+2.7 pp [+1.0,+4.2]、9/12改善
covariateなし58課題 同一pass 著者が完全一致を確認

skillは各taskのscaled quantile lossをseasonal naiveで割り、[0.01,100]へclipした比の幾何平均を1から引いて百分率にしたもの。CIはtask単位のbootstrapであり、全店舗の将来liftの区間ではない。

German day-ahead価格ではquantile loss −51%、Rossmannの日次売上では販促・祝日・営業日の追加で−43%。一方、M5では価格・calendar等8変数を入れても週/月粒度で差は±2%未満。小売に無関係というわけではないが、欠品を制御したTSFM対GBDTのbakeoffではない。

t0-alphaの事前学習に重なる8課題はbenchmark規則に従いChronos-Bolt値で置換し、全100課題skillは生予測42.9に対し報告42.2。t0-betaはbenchmark datasetを除いた事前学習を申告し全100課題で46.7。alpha→beta差はパラメータ数だけのcontrolled scaling実験ではない。

実行可能な理解

uv run papers/t0-tsfm-forecasting-with-context/run.py。公式モデルは実行せず、二つの局所監査を行う。第一に論文の丸め済みskillからpoint差と暗黙のloss比を計算する。第二に情報の依存graphを伝播し、既知未来zがtargetを逆参照すると、後のtargetが過去へ漏れる経路が生じることを確認する。加えてsoftplus累積で分位点の単調性を確かめる。

検証できたこと

Mechanism PARTIAL。報告値の算術、roleごとの情報境界、softplus累積分位点の順序は小計算でCONFIRMED。公式commitのCausalScalerとvariate attention / maskを静的に読んだ。論文のrole別非対称制限は確認した呼出経路に見つからず、mappingへ差を記録した。重みを使った予測は未実行。

検証していないこと

Performance / Scaling / Production applicability NOT TESTED。t0-alpha/beta、Chronos-2、ApolloPFN、GBDTの同条件再評価はしていない。販促×欠品、潜在需要、在庫費用、lead-time需要のjoint distributionは未検証。marginal quantileを足して注文期間のquantileとはしない。

論文と確認したコードの差

固定commitの MaskBuilder.build_group_mask() はgroup ID一致とpaddingの条件を作り、Transformer.forward() はそれをそのままvariate attentionへ渡す。確認した経路では、論文§4.1の「既知未来zはtargetを逆参照しない」というrole別制限を見つけられなかった。時間方向のfuture双方向maskとcausal scalerは確認できる。これは静的な不一致の記録であり、学習済みcheckpointでの未来情報漏洩を実証したものではない。モデル版・学習時コード・入力構築を含む追加監査が必要。
