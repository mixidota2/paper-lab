概要

販促は一日だけで終わるとは限らず、carryover と baseline を混ぜる。単純 smoothing は二つを同時に消してしまう。

問題設定

低い variance ratio は安全在庫を減らすが、event spike の under-provision を伴う。統計誤差と発注費用の目的関数は異なる。

核心

論文に書かれていること

CD は kernel-modulated banded operator で transient promotion shock と smooth baseline を convex に分け、hierarchical partial pooling で catalog scale にする。著者は M5 30,490 SKU と Favorita 2,845 item で、h/p が約 20% を超える時だけ総費用が低いと報告する。

読書メモ

この論文の良い点は『より安定』を無条件の勝ちにしないことだ。spike を薄める forecast は holding cost を下げても、stockout cost が重い業態では危険になり得る。

なぜ効きそうか

読書メモ — 著者による因果の立証ではありません。

読書メモ（推論）。kernel が impulsive response では identity に退避するなら、無理に carryover を作らずに済む。future promo calendar の可用性が前提である。

根拠

Abstract は holding/stockout 比の 95% CI [17%,25%] と catastrophic error の比較を記載する。単一著者の長い preprint なので、第三者の cost simulation で再確認したい。

実行可能な理解

uv run papers/contextual-deconvolution/run.py は baseline と stable forecast の費用順位が h/p で反転する表を出す。deconvolution は解かない。

検証できたこと

メカニズムは PARTIAL。variance を下げる選択の評価には、holding と shortage の比を明示する必要がある。

検証していないこと

operator fitting、partial pooling、M5/Favorita、error dispersion、bullwhip の実測は未検証である。

実装

短い deterministic cost sweep で、予測器の優劣ではなく decision boundary を示す。
