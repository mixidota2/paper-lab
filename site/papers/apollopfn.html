概要

需要は自己回帰的に見えても、販促や価格で不連続に動く。外生変数を無視する forecast は spike を過去ノイズと見なす。

問題設定

future covariate は予測時点で利用可能か、後から判明するかを分けなければならない。評価で未来の promo を渡すなら、同じ情報を baseline にも渡す必要がある。

核心

論文に書かれていること

著者は現行 TSFM の多くが外生変数を無視すると問題化し、temporal pattern、structural change、exogenous dependency を含む synthetic prior と time-aware architecture を持つ ApolloPFN を提案する。M5、電力価格、Air Quality、Solar で baseline を上回ると報告する。

読書メモ

価値は PFN という名前より、予測時に既知の promo/price を入力契約に入れる点にある。covariate の将来値がない運用では、この強みはそのまま使えない。

なぜ効きそうか

読書メモ — 著者による因果の立証ではありません。

読書メモ（推論）。prior が『価格が動くと需要が変わる』分布を含めば、few-shot fitting より前に関係を学べる。ただし店舗・SKU ごとの効果異質性は別問題である。

根拠

arXiv abstract は TMLR 2026 掲載と複数 benchmark の優位を述べる。Chronos-2 や同条件の GBDT と比較しない限り、実務選択の結論は限定的である。

実行可能な理解

uv run papers/apollopfn/run.py は販促週を含む八期の合成需要で、履歴だけと既知 flag を比べる。PFN の事前学習はしない。

結果

PFN の事前学習ではない。将来の販促が既知なら外生変数を使える、という最小例。

販促週の MAE が下がるのは、真の販促 flag を入力したためである。zero-shot 性能の検証ではない。

検証できたこと

メカニズムは PARTIAL。外生情報が将来に利用可能なら、履歴だけでは予測不能な spike を説明できる。

検証していないこと

SRNGN、RoPE/full attention、M5 RMSSE、PFN training、zero-shot transfer、production inventory cost は未検証である。

実装

標準ライブラリの平均絶対誤差だけを使う。結果は covariate availability の説明に限定する。
