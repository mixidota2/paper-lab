# DeepStock：出力の意味を変えて在庫DRLを学ぶ

## Overview

DeepStockは、ニューラルネットワークの出力を「目標在庫」や「需要特徴の係数」として解釈し、発注量へ変換する。在庫の構造を深層強化学習（DRL）へ持ち込む研究である。著者は2025年10月時点でTmallの対象商品100%、100万超のSKU–倉庫の組に展開したと報告する。4月の展開率は国際100%・国内87%で、時点を混同しない。

注目点は、方策が表せる範囲を狭めずに、学習時の探索を在庫管理に合う形へ寄せること。まず再写像の式を読むと、LLMが設計を担うSabreAgentやInvEvolveとは別の研究セルだと分かる。

## Problem

欠品後の需要は売上に残らない。DeepStockが扱うこの逸失販売型の在庫管理では、商品ごとに異なる販売規模、リードタイム、補充間隔を方策に渡す必要があり、Tmallの実験では190次元の特徴を使う。通常のDRLは発注量を直接出力するため、学習とハイパーパラメータ探索が不安定になりやすい。

販売数をそのまま真の需要とは置かない。著者は欠品時刻から当日の需要を外挿し、**推定した需要で訓練**する。推定誤差の影響は、本Labでは検証していない。

## Core Idea

著者の主張：BaseとCoeffは、ネットワーク出力から発注への再写像である。ネットワークは在庫状態も入力に取るので、固定の基準在庫方策へ制限されず、原理的には写像を打ち消す出力を学べる。

本Labの解釈：最適化する方策集合より、学習器が最初に見つけやすい行動を変える工夫と読む。研究地図では「在庫構造 × DRL」に置く。SabreAgentは設計時LLM→凍結したOR、InvEvolveはLLM→認証付き白箱方策の進化であり、DeepStockにLLMは登場しない。

## Method

Iは手元と輸送中の在庫状態、xは外生特徴、tot(I)は総在庫。f=feat(x)には4つの過去・予測需要と定数1を含む。μは状態に依存する学習済みネットワークである。

```text
None:  q = μNone(I, x)
Base:  q = max(μBase(I, x) − tot(I), 0)
Coeff: q = μCoeff(I, x)ᵀ f
Both:  q = max(μBoth(I, x)ᵀ f − tot(I), 0)
```

原論文の導入部pp.3–4の式。Coeffの式に独自の切り上げやクリップを加えていない。実験では非負の出力を使う。入力の動的特徴と在庫をSKU内で正規化し、Coeffで需要規模へ戻すため、販売規模をまたぐ単一方策の学習につながる。

## Why It Might Work

著者は、Baseが在庫過多での大量発注を避けやすくし、Coeffが需要規模に沿う発注を促すと説明する。Fig. 3ではBaseを使ったDDPGのBellman誤差が小さく、価値関数の学習が速い様子を示す。

解釈：人が決めた座標系で出力を読むことで、同じ表現力でも学習経路は変わる。ただしμ自体が状態依存なので、「在庫が増えると必ず発注が減る」「需要が増えると必ず発注が増える」という単調性保証にはならない。下図は出力を固定した断面である。

## Evidence

以下は一次資料の著者報告であり、本Labによる追試結果ではない。[原論文Table 1・2、§4](https://arxiv.org/pdf/2603.19621v1)に対応する。

オフラインのTable 1はDDPG Bothとの差を示す。DDPG Noneは欠品率+10.10ポイント、回転日数+6.13日。DS Noneは+2.10ポイント、−1.25日。DS Baseは+2.18ポイント、−2.81日なので、DDPG Bothは欠品率で勝つが回転日数では劣る。著者は欠品率を回転日数の2倍重く扱う評価で、DDPG Bothを最良とする。両指標の同時優越と読んではいけない。

2024年7月のDiDは、改善余地の大きい国際SKUを選抜した10%が対象。欠品率−0.83ポイント、回転日数−9.53日。無作為割付ではなく、全SKUで同じ効果が出るとは限らない。

2025年4月は旧方策を実際の補充間隔・リードタイムで動かす反実仮想シミュレーションと比較した。国際SKUで約−1日、国内で約−2日、欠品率に判別可能な差はない。国内A+は−4.04日。在庫価値50億人民元を前提に、在庫削減3.5億人民元、年間資本費用削減1,330万人民元と推計する。日本円ではない。

## Executable Understanding

対話図では、ネットワーク出力を固定して在庫だけを動かす。Base/Bothの傾きとゼロへの切り詰め、None/Coeffの水平線を比べる。同じ水平線でも、Coeffは需要特徴の加重和として生成される。

さらに任意の非負発注qについて、Baseならμ=q+tot(I)、Bothなら定数特徴の係数にq+tot(I)を入れればqを復元できる。55組の在庫・発注を使ってこの恒等関係を確かめる。有限標本の構成確認であり、ニューラルネットワークの学習成功を証明するものではない。

## Results

最小実験では55組すべての復元誤差が0。目標12・24・36、在庫0〜48の断面で、同じ目標値を表すBaseとBothの発注は一致した。需要特徴は[4, 8, 12, 16, 1]、最初の4係数は[0.1, 0.2, 0.3, 0.4]とした。

性能の改善量は測っていない。図の欠品率・回転日数は論文から転記した値であり、この実験の出力とは区別する。

## What We Verified

CONFIRMED：原論文の再写像を数式どおり計算し、非負発注を復元する55例の誤差が0であることを確認した。Base/Bothの同一目標での一致も確認した。

PARTIAL：機構全体の検証は限定的。固定出力による代数的な確認だけで、DDPG・PPO・DSの学習は実装していない。

## What We Did Not Verify

NOT TESTED：DRLの収束速度、ハイパーパラメータ感度、Table 1の性能順位、100万超のSKU–倉庫への拡張、実運用の因果効果。Tmallの非公開データ、欠品需要の復元、報酬重み、実運用の再学習を再現していない。
