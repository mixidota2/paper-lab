# 論文と教材の対応

[一次資料：論文の初版](https://arxiv.org/html/2609.28589v1)。本文では図1〜4、式4、表2・4、§6.3と§7.9を参照しています。保存した[論文PDF](https://arxiv.org/pdf/2609.28589)のSHA-256は `166a1ec87e118921fd9fa2130f7648097df65e9ebcfe096097ea29c0df50f951` です。

| 論文 | 教材で行うこと | 教材で確かめていないこと |
| --- | --- | --- |
| 図2：3段階が利用者の履歴の計算を共有する | `cache_cost` は、履歴を3回計算する場合と1回の結果を使う場合の作業量を、仮の単位で比べます。 | GPUのキャッシュや毎秒の処理件数は測りません。 |
| 図3と式4：検索の目的を先に選び、商品コードを作る | `rank()` は3候補すべての得点を計算し、業務上の加点で順位がどう変わるかを比べます。 | 商品コードの学習やビーム探索は実行していません。 |
| 図4：複数の表示で履歴計算を共有する学習 | 記事で、表示より後の行動は入力に入れないことを説明します。 | SNTやTransformerは学習させていません。 |
| 表2・4、§6.3、§7.9：過去データと本番の評価 | 記事では、演算量、学習速度、実際の配信速度、利用者当たりの取引額を別々に示します。 | 著者の比較実験は実行していません。 |

確認した論文PDFから、著者が公開した実装のURLは見つかりませんでした。実装が公開されていないと断定するものではありません。Labが配布する `run.py` は説明用に作ったコードです。

`lab.yaml` に記事と図、`method.md` に手法、`run.py` に計算、`results.json` に結果を置き、HTMLを生成します。論文の数値と教材の計算結果は別に表示します。
