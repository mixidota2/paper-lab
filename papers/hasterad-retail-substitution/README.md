# 同じ売上を予測するモデルでも、商品を外すと答えが分かれる

全商品が買えるときの販売を同じように説明できても、一部の商品を外したときの購入先までは同じように予測するとは限りません。Labは架空の4商品を使い、顧客が同じブランドの商品に移る確率と、何も買わない確率を比べます。棚に2品だけを残す場合は、モデルによって期待粗利が最も高い組み合わせが変わります。

## 実行方法

リポジトリのルートで次のコマンドを実行してください。入力データをダウンロードする必要はありません。最初のコマンドが、このLabと同じディレクトリの `results.json` へ計算結果を書き出します。

```sh
uv run python papers/hasterad-retail-substitution/run.py
uv run paper-lab build
```

`results.json` には、画面で選べる5つの条件と、4品から2品を残す全6案の期待粗利が入っています。スライダーを動かすと、Web画面が対応する保存済みの値を表示します。
