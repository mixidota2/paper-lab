# 商品を外したとき、買い替え先の予測で品ぞろえの判断は変わるか

全4商品が買えるときは、二つのモデルが同じ購入確率を出します。Labでは架空の品ぞろえから商品を外し、同じブランドの別商品や別ブランドを買う確率、何も買わない確率を見比べます。2品だけを残すなら、各モデルでどの案が最も粗利を得られそうかも確かめられます。

## 実行する

リポジトリのルートで、次のコマンドを実行します。外部の入力ファイルは使いません。

```sh
uv run python papers/hasterad-retail-substitution/run.py
uv run paper-lab build
```

最初のコマンドは `run.py` と同じ場所の `results.json` に、画面で選べる5つの条件と、4品から2品を残す全6案の期待粗利を書き出します。二つ目のコマンドで記事を生成します。スライダーは、選んだ条件に対応する保存済みの確率と粗利を表示します。
