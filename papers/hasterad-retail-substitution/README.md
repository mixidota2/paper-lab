# 商品を外したとき、どの売上が残るか

すべての商品を並べたときには予測が一致しても、棚から商品を外した後の予測は一致しないことがあります。Labでは架空の4品で、同じブランドへの代替と、買わない選択の両方を比べます。残せる商品が2品の場合には、2つのモデルで粗利が最も高い組み合わせが変わります。

## 実行方法

リポジトリのルートで実行してください。結果は同じLabの `results.json` に書き出します。入力データのダウンロードは必要ありません。

```sh
uv run python papers/hasterad-retail-substitution/run.py
uv run paper-lab build
```

`results.json` には5つの表示条件と、4品から2品を残す全6案の期待粗利を収録しています。Web画面でスライダーを動かすと、同じ計算結果を読み込んで表示します。

## 原論文と異なる点

原論文はまず何の属性で商品がまとまるかを売上データから推定します。Labではブランド別と階層なしの構造を先に与え、同じ商品シェアから出発するように重みを決めます。著者の推定手順と利益評価は再現していません。出典と対応は [mapping.md](mapping.md)、論文で報告された結果の条件は [evidence.md](evidence.md) にあります。
