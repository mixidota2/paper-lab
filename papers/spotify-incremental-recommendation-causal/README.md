# Spotify：推薦なしでも再生しそうな作品を外す

## 概要

Spotifyの研究チームは、推薦しなくても利用者が再生しそうなコンテンツを、ホームでの推薦対象から外す方法を試しました。モデルは、推薦を見た直後に再生する確率と、推薦を受けずに2日以内に自然に再生する確率を別々に予測します。観測期間が違うため、著者は確率を引き算しません。推薦後の確率が高く、自然再生の確率が低いと予測した場合にだけ表示します。

同じモデルを使った2週間のA/Bテストで、推薦後の確率だけを使う方法と比べると、利用者当たりの推薦表示は7.1%減りました。推薦対象コンテンツの再生時間は0.37%減りましたが、統計的に有意な差はありませんでした。この比較が測ったのは、ホームで表示する条件を変えた効果です。個々の推薦が再生を増やしたかは測っていません。

## 比較の範囲

Spotifyはホームを使う数百万人を対象に、2週間のA/Bテストを行いました。表1では、同じモデルと学習データを使い、表示後の確率だけで選ぶ群（Treatment-Model）と、自然再生の確率も使って選ぶ群（Treatment-Causal）を比べました。従来の別モデルとの比較ではありません。

| 指標 | 相対差 | 95%信頼区間 |
| --- | ---: | --- |
| 利用者当たりの推薦表示 | −7.1% | [−7.2%, −6.9%] |
| 推薦対象コンテンツの再生時間 | −0.37% | [−0.86%, +0.21%] |

再生時間の信頼区間はゼロを含みます。再生時間がまったく変わらないことや、許容した減少幅を超えないことの証明ではありません。掲載値からは、その許容幅を確認できません。著者は残った約93%の表示を追加の再生につながる表示と解釈していますが、個々の表示について因果効果を直接測った割合ではありません。

図4では、同じ予測確率を付けた組が実際にどれくらい再生したかを比べました。推薦後の再生の出力は、従来モデルより予測と実績が近くなりました。推薦を見送った場合の出力について、著者は高い確率で見えるずれを標本の少なさで説明しています。論文の図から誤差の数値は補っていません。

## 手元で計算する

このフォルダーで `uv run --no-project python run.py` を実行します。標準ライブラリだけを使い、結果を `results.json` に保存します。

推薦後の確率だけで選ぶと、4組のうち3組に表示します。θ₀=0.5を加えると2組です。仮定した確率から計算すると、4組分を合計した期待値は、推薦で増える再生が0.82から0.80、全再生が2.37から2.35に下がります。表示を減らしても、再生をそのまま保てるとは限らない例です。

推薦後の再生確率の下限は0.4に固定し、自然再生の確率をどこまで許すかだけを変えます。

## 資料の読み方

`method.md` は二種類の記録での学習と表示条件、`mapping.md` は論文と教材の対応を説明します。式5と論文の説明に閾値の向きが逆の箇所があり、教材は式の向きに従っています。

この教材はSpotifyの学習、予測確率の評価、本番実験を再現しません。異なる期間の二つの確率を引いた値も、推薦で増えた再生とはみなしません。
