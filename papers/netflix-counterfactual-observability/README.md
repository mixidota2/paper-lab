# Beyond Raw Engagement: A Counterfactual Observability Framework for Recommender Systems at Netflix

よく見られた作品でも、代わりの作品が同じように見られるなら、その作品を外す影響は小さくなります。Netflixの論文は、実際に見られた量と、作品を外すと失われる反応をどう見分けるかを調べました。著者はホーム画面の推薦枠の貢献を探索ログで推定し、実際に枠を外した11件のA/Bテストで測った反応の減少と比べました。決定係数R²は0.8212でした。この値はその11件についての比較で、新しい推薦枠でも同じ精度になるとは限りません。

## 手元で人工データの計算を実行する

配布した `run.py` はPython標準ライブラリだけで動きます。保存したフォルダーで `python run.py` を実行すると、同じ場所に `results.json` を書き出します。リポジトリを取得した場合は、ルートで次を実行できます。

```bash
uv run papers/netflix-counterfactual-observability/run.py
uv run paper-lab build
```

1行目は人工データの計算、2行目はサイトの生成です。

## 同じ探索ログで、作品Aを残した場合と外した場合を比べる

Labは利用者の状況を2種類、候補を3つ、表示枠を1つに絞りました。選択確率とクリック確率を先に決め、同じ探索ログから二つの方式のクリック率を見積もります。一方は作品Aを残し、もう一方はAを取り除き、必要なら代わりにBを表示します。設定から求めた期待クリック率は0.36と0.32です。差の0.04は、この人工例でAを外したときに失う分で、Aそのもののクリック率ではありません。

別の人工例では、作品が候補に入ったときの差に、候補に入る確率を掛けます。前者が0.08と0.03、後者が0.20と0.80のとき、掛け算の結果は0.016と0.024です。候補に入ったときの差だけを比べる場合と、全体での貢献を比べる場合では順番が逆になります。

## 確認した範囲と、読む資料

固定した人工データで、選択確率で重み付けした推定と、設定から直接計算した値を照合しました。仕組みの検証は一部（PARTIAL）です。Netflixの実ログ、11件のA/Bテスト、著者のシミュレーションは追試していません。実データでの精度、大規模な処理、本番環境への適用も検証していません（NOT TESTED）。

モデルと図は [method.md](method.md)、原論文とLabの対応は [mapping.md](mapping.md)、本番テストの報告と確認範囲は [lab.yaml](lab.yaml) にあります。計算の入力と出力は [run.py](run.py) と [results.json](results.json) にあります。
