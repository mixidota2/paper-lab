# 論文とLabで確かめたこと

論文は本番ログで重みの集中を調べ、真値を作れる別のシミュレーションで推定誤差を測りました。Labは実サービスを再現せず、確率が分かっている架空の64商品で計算を確かめました。

| 原論文 | Labで対応する処理 | 確認の範囲 |
| --- | --- | --- |
| §2：グループ単位のIPSとSNIPS | `cluster_masses` と `experiment` が、新旧のグループ確率の比でログの報酬を重み付けする。 | ユーザーなどの条件が変わらない人工例を使う。 |
| §2：先頭の符号からグループ確率を求める | `decoder_prefix` が、段ごとの条件付き確率を掛ける。 | 各商品の既知の確率から条件付き確率を作る。実際のデコーダは学習しない。 |
| 命題3.1：グループ単位IPSの偏り | 手法欄に上限を記し、`exact_IPS_bias` には人工例で求めた期待値の偏りを保存する。 | 埋め込みに対する報酬の変化の上限を推定せず、論文の不等式の実証もしない。 |
| §4：本番ログと別の制御実験 | 乱数シードごとに推定し、RMSEとESSを保存する。 | 論文のデータや公式コードを使った追試ではない。 |

出典は[論文初版のPDF](https://arxiv.org/pdf/2608.28905v1)。論文のデータや公式リポジトリは取得しておらず、公式実装も実行していません。
