# Auto-RecSys: Harnessing Autonomous Research Agents for Industry-Scale Recommender Systems

Auto-RecSysは、1回の学習に数日かかる推薦モデルの実験を、案ごとに分けて複数のサーバーで進める仕組みです。著者は、どこまで進んだかを案ごとに保存し、以前のセッションが終わっても作業を続けられるようにしました。ジョブが失敗した原因と対処は、次の実験でも読めるようにモデル別の手順書へ残します。

著者は一つのモデルの31回の運用ログを調べました。実験1回あたりの大きな運用上の修正は、立ち上げ期の平均4.0回から、基準モデルが変わる前の安定期には平均1.3回に減りました。基準モデルの変更直後は5回続けて復旧が必要になり、その後の6回では平均0.5回でした。対照群がないため、この変化を手順書だけの効果とは判断できません。これらは学習時間や推薦精度を測った数字でもありません。

配布ファイルの `run.py` を `python run.py` で実行すると、同じフォルダに `results.json` が出力されます。Pythonの標準ライブラリだけで動きます。Labは学習時間と失敗の種類を仮定し、人が手を動かした時間と全実験が終わるまでの時間を別々に集計します。論文の31回を再現したものではありません。

本文と仕組みの説明は `lab.yaml` と `method.md`、論文とLabで確かめた範囲の対応は `mapping.md` にあります。
