# Auto-RecSys: Harnessing Autonomous Research Agents for Industry-Scale Recommender Systems

Auto-RecSysは、結果が出るまで数日かかる推薦実験を、複数のサーバーで並行して進める仕組みです。実験ごとに、学習中か結果の確認待ちかといった状態を共有領域に残すので、エージェントのセッションが終わっても別のセッションで続けられます。過去の失敗と対処はモデル別の手順書に残し、状態の更新や入力の検査は決められた処理に任せます。

著者が1モデルで追った31回の実験では、ジョブの再投入など、運用上の大きな修正が1回の実験あたり平均4.0回から1.3回に減りました。基準モデルが変わった直後には5回続けて復旧が必要になり、その後の6回では平均0.5回でした。対照群のない運用記録なので、手順書だけの効果とは言えず、学習が速くなったことや推薦精度が上がったことを示す数字でもありません。

`uv run papers/auto-recsys-harness/run.py`

本文の原稿は `lab.yaml` と `method.md`、原論文との対応は `mapping.md` です。`run.py` は標準ライブラリだけで動き、同じディレクトリに `results.json` を生成します。出力は条件を設定して作った例で、原論文の数値を再現したものではありません。
