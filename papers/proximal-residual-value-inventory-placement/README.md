# Proximal Residual Value Functions for Consistent Planning and Real-Time Execution

Amazon SCOTの著者は倉庫に届いた商品をどの拠点へ何個置くかを扱いました。計画側は配分後の在庫が将来どれだけ費用を生むかを見積もる式を作り、実行側は入荷のたびにその式とその時点の費用や制約を使って置き先を決めます。State-proxは学習した費用の見積もりに、置いた後の在庫量に応じた項を足し、学習と実行で同じ式を使います。

学習に使っていない商品と期間でシミュレーションしたところ、需要を満たした数量当たりの配送・移送費用は、過去の運用を模した方法より5.0%低くなりました。比較相手を1としたときの費用は0.950です。この数字は実際の物流網で運用を変えた結果ではありません。入荷の合間に需要や費用が変わる場合は、同じ配分になるとは限りません。

## 問題設定

この研究は、すでに届いた在庫をどの拠点にいくつ置くかを扱います。DeepStockやORPRのように、補充のために何個買うかを決める研究ではありません。計画側は、置いた後の在庫から将来費用を見積もる式を商品と期間ごとに用意します。実行側は入荷のたびに、その式に現在の移送費を足し、制約を守って置き先を決めます。

計画では入荷をまとめて扱い、実行では届くたびに配ると、同じ在庫の評価式を使っても最終在庫は一致しないことがあります。計画時と実行時で最適化の目的が違うことも、別のずれを生みます。論文はこの二つを扱いますが、同じ式を解くときの計算精度の違いや、入荷の間に需要や費用が変わることまでは解決していません。

## 配置後の在庫を評価する仕組み

著者は、凸な区分線形の残差に、配置後の在庫を評価する項を加え、計画と実行で同じ式を使います。さらに、環境を固定して連続量を配る問題で、入荷の分け方が変わっても最終在庫が一致する条件を示しました。

この研究で決めるのは、届いた在庫の置き先と数量です。置き先を決める式を学び、各回の入荷に対して制約を守る配分を計算します。発注する量を決める研究や、提案した行動を制約内に直す研究とは、対象が異なります。

## 計画と実行で使う在庫の評価式

計画側のモデルは、商品と期間ごとに、配置後の各拠点の在庫から将来費用を見積もる式を出します。このモデルを学習する際は、期間内の入荷をまとめて最適化を解き、その計算を通してモデルを更新します。実行側は入荷のたびに、この式を使って将来費用を見積もり、その時点の移送費と配置の制約も踏まえて置き先を決めます。

### 配置後の在庫に加える項

式(6)の `Vη(x)=Rη(x)+τΣφ(xᵢ)` では、`x` が配置後の在庫です。前半が学習する残差で、後半は配置後の在庫に応じて変わる項（状態ポテンシャル）です。

| 項 | 式で何を計算するか | 何を保証しないか |
| --- | --- | --- |
| 拠点別の残差 | 拠点ごとに凸な区分線形関数 `fᵢ(xᵢ)` を使います。折れ点を境に傾きが変わります。 | 折れ点の間は直線なので、この項だけでは曲率がつきません。 |
| 拠点間の結合 | 学習した重み `wℓ` を複数拠点の在庫に掛け、凸な区分線形関数 `hℓ(wℓᵀx)` で評価します。 | 重みに負の値があっても凸性は保てますが、入荷の分け方を変えたときの一致は保証しません。 |
| 状態ポテンシャル | 配置後の在庫に狭義凸な項を加えます。主実験では `φ(x)=x log x` です。 | 狭義凸性は各回の最適解を一つにしますが、一括と分割で同じ解になるとは限りません。 |
| 各回の配置量に加える項 | 配置後の在庫ではなく、各回に置く量 `z` を評価します。 | 一括の `Ω(z₁+z₂)` は、分割した `Ω(z₁)+Ω(z₂)` と一般に一致しません。 |

### 一括配置と分割配置が一致する条件

一度置いた在庫を戻せないとき、一括で選ぶ各拠点の在庫が総入荷量の増加に伴って減らなければ、先に置いた在庫が後の最適な配置を妨げません。論文の命題1では、初期在庫と線形費用を固定し、連続量を一つの総量制約の下で配り、最適解が一つに決まるとします。この範囲では、この単調性が、どの総入荷量・どの有限な分け方でも最終在庫が一致するための必要十分条件です。

論文の定理1は、評価式が非負領域の近くで2回連続微分可能で、非負領域でヘッセ行列が正定値の場合を扱います。どんな初期在庫と固定した線形費用でも、入荷の分け方にかかわらず最終在庫が一致するための必要十分条件がPCSPです。在庫状態のどの点でも、拠点のどの非空集合 `A` に対しても、対応する部分行列の逆行列を全成分1のベクトルに掛けた `H_A⁻¹1_A` の各成分が0以上になることをPCSPと呼びます。逆行列の個々の成分がすべて0以上である必要はありません。たとえば `H=[[2,1],[1,2]]` は逆行列の対角以外に負の値を持ちますが、行の和は両方とも1/3です。拠点を一つに選んだ部分行列でも1/2となり、この例は条件を満たします。

図3の `H=[[2,3],[3,5]]` も正定値ですが、二つの拠点を取ると `H⁻¹1=(2,−1)` です。一括での最適な在庫は総入荷量1では(0,1)、総入荷量2では(2,0)なので、第2拠点の在庫は減ります。実行時に1ずつ届く場合、初回に第2拠点に置いた1を戻せず、2回目の後は(1,1)になります。

区分線形関数では折れ点があるため、上の微分条件をそのまま使えません。命題2は、重みが拠点集合の指示ベクトルで、集合が入れ子か互いに重ならず、結合関数が凸で、拠点ごとの項が狭義凸の場合に一致を示します。主実験の学習済み結合は複数拠点に正負の重みを持つため、この保証の対象ではありません。整数配分、追加の結合制約、費用や需要が入荷の間に変わる場合にも、上の判定をそのまま使えません。

### Labで計算する範囲

Labは図3の反例に加え、残差 `R(x)=|x₁−0.5|+2|x₂−3|` と二次の項 `Φ(x)=‖x‖²/2`、`τ=1` を使う二つの例を計算します。二次の項を配置後の在庫に加える場合と、各回に置く量に加える場合を比べます。一括ではどちらも(0.5,1.5)ですが、分割すると各回の配置量に項を加えた例は最終在庫が変わります。Labは論文のState-proxの学習、エントロピーを使う項、逆伝播を実行していません。

## 入荷の分け方によって配置が変わる理由

毎回の配置量に二次の項を加えると、1回で置くときと何回かに分けて置くときで、その項の合計が変わります。配置後の累積在庫を評価する形なら、計画と実行は同じ式で最終在庫を評価できます。ただし、先に置いた在庫を戻せない以上、同じ式を使うだけで一括と分割が一致するわけではありません。

初期在庫と線形費用を固定し、連続量を一つの総量制約の下で配るときは、一括で選ぶ各拠点の在庫が、総入荷量の増加に伴って減らないことが鍵です。狭義凸性は最適解を一つにしますが、この条件までは保証しません。論文は、滑らかな評価式を調べるPCSPと、拠点の集合が入れ子か互いに重ならない区分線形の形に対する保証を分けています。実験で学習した正負の結合は後者の保証外なので、著者は分割による差を別の実験で測りました。

## 論文の費用評価と分割実験

一次資料は[原論文v1の§6、表1、図4](https://arxiv.org/html/2609.23242v1)です。表1では、100万商品超を含む履歴データをもとにしたシミュレーターで、52週間の配置を評価しました。100万は元データの商品数であり、導入試験の件数ではありません。学習外の評価では、学習に使わなかった商品と別の期間を使いました。同じ区分内では、各方式に同じ入荷・需要・移送費の条件を与えています。

| 方策 | 学習内の費用 | 学習外の費用 |
| --- | --- | --- |
| 過去の運用を模した比較方式 | 1.000 | 1.000 |
| 配置量を直接出すニューラル方策 | 0.881 ± 0.007 | 1.012 ± 0.002 |
| State-proxと状態ポテンシャル | 0.851 ± 0.022 | 0.950 ± 0.028 |
| 同じState-proxの残差で状態ポテンシャルを外す | 0.933 ± 0.028 | 1.070 ± 0.038 |

費用は、配送と移送の合計を需要を満たした数量で割ったもの（SCPUT）です。容量価格のペナルティは含みません。学習内・学習外のそれぞれで、過去の運用を模した比較方式を1にそろえています。±は学習を繰り返したときの標本標準偏差で、信頼区間ではありません。State-proxで状態ポテンシャルを残したときの0.950は、比較方式より5.0%低い値です。状態ポテンシャルを外すと、残差だけではMirror-proxの残差より費用が高くなりました。表は評価式と学習方法を組み合わせた結果であり、一つの変更だけの効果ではありません。

表1では、標準正規乱数にμを加え、負なら0にした値を移送費に足しました。学習時のμは1.349、評価時は0です。評価時も費用への加算は残ります。著者は学習した区分線形の方策をGurobiで解き、直接配置するニューラル方策と過去の運用を模した比較方式は、それぞれ元の実行方法を使いました。

図4は表1とは別の実験です。著者はμ=0で方策を学習し、各パネルで商品と週の組を5,000件使いました。入荷元ごとの数量や費用などを固定し、一括で配る場合と500回に分ける場合を比べました。学習外の最終在庫の差を表すTVはState-proxが0.00201、直接配置するニューラル方策が0.12716でした。TVは在庫を一致させるために置き先を変える必要がある入荷量の割合で、費用の削減率ではありません。図4は差が完全に消えることや、何期にもわたる費用差を示す実験ではありません。

## 図の操作

図では、2拠点に合計2単位を1・2・5・20・500回に分けて配ります。どの条件でも初期在庫は0、入荷の間に需要や費用は変わりません。図3の反例は、H=[[2,3],[3,5]]、a=(0,1)、線形費用0です。一度置いた在庫は次の回に戻せません。

Labは、拠点ごとの区分線形残差に二次の項を加えた二つの例も計算します。一つは配置後の累積在庫に、もう一つは各回に置く量に二次の項を加えます。総入荷量が同じなら一方の拠点への配置量から他方も決まるため、図3の反例は式から、残り二つは一変数の凸最小化を二分探索で解きます。論文のState-proxの学習や最適化の逆伝播は実行しません。

## Labの人工例

図3の反例では、一括なら最終在庫は(2,0)、2回なら(1,1)です。入荷量の半分を別の拠点に置けば一致するので、TVは0.5です。5回では(1.2,0.8)、20回と500回では(1,1)になりました。この例では、分割回数を増やせば差が必ず増えるわけでも減るわけでもありません。

配置後の累積在庫に二次の項を加えた例では、試した全条件で(0.5,1.5)になりました。各回の配置量に二次の項を加えた例では、一括が(0.5,1.5)、2回以上が(0,2)でした。いずれも浮動小数点の丸めの範囲での値です。この計算は限定した式を使った人工例であり、著者が学習した正負の結合を持つ方策の結果ではありません。

## 確認したこと

CONFIRMED（確認済み）：図3の正定値行列でも、分割によって配置が変わりました。H⁻¹1=(2,−1) の負の成分は、一括で配る量を増やすと拠点2の最適在庫が減ることに対応します。

PARTIAL（一部確認）：Labは、拠点ごとの区分線形残差と二次の項だけを使い、累積在庫を評価する場合と毎回の配置量を評価する場合を比べました。表1の費用評価を再現したわけではありません。

## 確認していないこと

NOT TESTED（未検証）：Labは強化学習、State-proxの陰関数微分、Gurobiでの実行、表1の0.950、100万商品規模での実行や現場導入を検証していません。入荷の間に需要や費用が変わる場合は、原論文の一致の保証の対象外です。PCSPは、一つの総量制約の下で連続量を配り、環境を固定した問題についての条件です。
