# GenPage：Netflixはホーム画面に行と作品をどう並べるか

## 論文の概要

Netflixの研究チームは、ホーム画面に並べる行と、それぞれの行に載せる作品を、一つのTransformerで順に決めるGenPageを提案しました。利用者の視聴履歴やすでに表示した行を入力し、既存の候補集合の中から次の行と作品を選びます。

14日間のA/Bテストでは、約2億パラメータのモデルを従来の多段階の推薦と比べました。最も成績のよかった設定では、採用判断に用いる主要な利用指標が0.24%増えました（95%信頼区間は0.17〜0.30%増）。著者は、配信全体にかかる時間が20%短くなったとも報告しています。本番で試したのは、重み付きの二値分類で追加学習したモデルです。強化学習版や、既存の候補生成まで置き換える構成は、この本番比較の対象ではありません。

## 研究チームが変えたこと

Netflixのホーム画面では、単に評価が高い作品を選ぶだけでは足りない。たとえば「視聴中の作品」を上に置くと、利用者は続きの再生を始めて、下の行を見ないことがある。同じ作品を別の行に置くと、違う作品を見つける機会も減る。行と作品の順位を別々に決める方式では、後からこうした関係を調整する必要がある。

GenPageは行と作品の並びを一つの出力として扱う。ただし、本番実験でモデルに渡したのは既存システムが用意した行と作品の候補である。どの候補を出せるかの判断まで全部置き換えたわけではない。Gryphonのように、商品や作品を表す記号から候補を探す仕組みとの違いはそこにある。

## 論文の実験

### Netflixは既存の候補を使って並べ方を比べた

著者は、約2億パラメータの重み付き二値分類モデルを、従来のホーム画面の推薦処理と14日間比べた（§8、図6）。著者が試した5設定では、無作為に加える負例の量や、学習に採用する表示記録の条件が違う。主要な利用指標はいずれも改善した（p<0.001）。最良の設定では0.24%増え、95%信頼区間は0.17%から0.30%増だった。指標の詳しい定義、割り付けの割合、参加人数は公開されていない。下の図には14日目の値だけを載せた。

変わったのはホーム画面を届けるまでの応答時間で、従来より20%短くなった。著者は順位付けと特徴計算を減らしたこと、行と作品をIDで表したこと、行末をまとめて選んだことを理由に挙げている。どの変更が何%を占めたかはこの比較からは分からない。

### 事前学習と強化学習は、別のログ比較で評価した

表1では、同じ追加学習を事前学習ありとなしで比較した。あり・なしの順に、損失は0.321と0.333、行のAUCは0.884と0.879、作品のAUCは0.920と0.910だった。図3はモデルの大きさを変え、図4は入力に含める情報を段階的に増やした。学習設定やデータの時点が異なるため、同じ条件で試したようには比べられない。

強化学習で多様性が上がったのは、配信前の評価である（図5）。学習時と評価時に同じ報酬予測モデルを使ったため、評価値が上がっただけで利用者の満足度が上がったとは言えない。本番の重み付き二値分類版でも、新作と既存作品、映画とシリーズの表示割合などに、意図しなかった変化が出た。著者はこの原因を調べる必要があるとしている。

## 合成例を実行する

```sh
uv run papers/genpage-netflix-homepage/run.py
```

Labは2行に3作品ずつ並べる例を用意した。候補に含まれない作品OUTには、許可した作品より高い点を与えた。また、先にAを選んだ場合はCの点が上がるようにした。この二つの条件を固定し、候補を制限するか、行末をまとめて選ぶかだけを変えた。行末をまとめて選ぶときは、その部分の途中で作品を追加してもスコアを計算し直さない。

## 合成例の結果

候補を制限しないと、合計6か所すべてで候補外のOUTが選ばれた。候補を制限すると、候補外の作品は一つも選ばれなかった。全作品を一つずつ選ぶと採点は8回だった。先頭の作品だけを一つずつ選ぶ条件では6回で、並びはこの例では変わらなかった。行を丸ごと一度に採点する条件では4回だったが、1行目はA・C・BではなくA・B・Cになった。

## Labで確認できること

Labは、この合成例の範囲で、候補を除く規則と、行末で採点を繰り返さない場合の並びを確かめた（Mechanism: PARTIAL）。[結果](results.json)のCONFIRMEDは、この例で確認したことを示す。

## Labで確認していないこと

LabはNetflixのデータや実際に使う反応の集計方法、約2億パラメータのモデルを使っていない。強化学習の本番効果、Gryphonとの比較、配信時間は測っていない（NOT TESTED）。先頭だけ一つずつ選ぶ方法と全作品を一つずつ選ぶ方法が、この例で同じ順になることは確認できた。別の作品や採点方法でも一致するとは限らない。
