# 積と比を比べる

DCDNはクリック数と表示数のような二つの数から、比を含む特徴の組み合わせを学ぶモデルです。このLabでは、分子を正の値に固定して、正の分母を変えます。分母を小さくするほど積は小さくなり、比は大きくなります。逆数を使う項が元の比と一致する条件と、分母がゼロに近くて一致しない条件を画面で比べられます。

配布版の `interactive.html` はブラウザーで開くだけで使えます。手元にPython 3があれば、同じフォルダーで `python3 run.py` を実行できます。`results.json` には、架空の学習・評価データ、求めた重みと誤差、論文の表5の値が入ります。

Labは論文のモデル全体を学習し直したわけではありません。本番の性能も測っていません。[一次資料](https://arxiv.org/html/2611.27514v1)の結果と、Labで計算する内容の対応は `mapping.md` に記載しています。

画面の初期値と操作後の表示は、配布版を指定して `node test.cjs interactive.html` で確認できます。
