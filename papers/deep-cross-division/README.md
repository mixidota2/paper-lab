# 積と比を比べる

分母を小さくすると、積は小さくなりますが、比は大きくなります。DCDN が使う逆数の項がどこまで元の比と一致するかを、自作例で確かめます。

Python 3 があれば、同じフォルダーで `python3 run.py` を実行できます。結果の `results.json` には、自作例の学習・評価データ、求めた重みと誤差、論文の表5の値が入ります。配布版の `interactive.html` はブラウザーで開くだけで使えます。

論文のモデル全体や本番での性能を再現するものではありません。[一次資料](https://arxiv.org/html/2611.27514v1)と自作例の対応は `mapping.md` に記載しています。

生成した画面の初期値や操作後の表示は、`node test.cjs interactive.html` で確認できます。配布版の HTML を指定してください。
