# 論文のどの部分をLabで試したか

[一次資料：原論文v1](https://arxiv.org/pdf/2609.27606v1)。下のSHA-256は2026年9月25日に照合した保存済みPDFの値です。

`9699ce249f7cf0b31394687f95ced4864c4612a622eb59f1d4e3ea9dbb937c99`

| 原論文 | Labで扱う内容 | Labで扱わない内容 |
| --- | --- | --- |
| §3、図1、式1〜2 | 状態の対応表で、W1の出力がW2とW3に渡ることを示す | 3機能を本番と同じ環境で接続する処理 |
| §4、式3、表6 | `freeze_tools()` は、登録例2組を使い、先に使うツールを決められるかを返す | 約50組の全表、出力を受け取りながらの解析、実ツールの実行 |
| §5、式4、表7 | `ground()` は、所持条件を満たさない候補を除く | 自然言語からの条件抽出、重要度の3段階すべて、段落の選択 |
| §6、図2、付録E | `schedule()` は待機中の候補を除き、抽選し、`replay()` が履歴を更新する | 実際の会話への組み込み。教材の待機は1ターン |
| §7、表3〜4、付録G | 著者らが報告した比較値を表と図に整理する | 200セッションの再評価、速度や製品の効果測定 |
| §8、付録F | 他の分野に当てはめる場合の考え方を扱う | ECやコード補完などで導入して効果を測ること |

論文の§4と付録A.1は、意図、詳しい意図、前置き、計画の順で説明しています。図4のキャプションでは前置きが先にあります。Labは本文の順序を採用し、模式図に書かれた時間は実測値として使っていません。

確認した論文にはSGC全体を再現する実装へのリンクがありません。付録G.11は評価データや各機能の定義を今後公開する予定としています。公開の有無は網羅的に調べていません。`run.py` はLabが作った教材です。
