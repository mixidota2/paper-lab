# 原論文の各式を、教材のどこで使っているか

| 原論文 | 教材で比べること | 計算の場所 |
| --- | --- | --- |
| §3.1、式(1)と(4) | 置かなかった商品から移る需要を、採用商品の基礎需要の比で配る。 | run.py の evaluate と eq4、model.js の evaluate |
| 式(6)、(9)、(10) | 候補を棚幅に収め、採用商品の基礎需要が下限を満たすかを確かめる。採用商品には面数を一つ選ぶ。 | evaluate、oracle、values |
| 式(7)〜(8) | 商品を一つ以上採用したブランドだけ数える。 | 採用した商品からブランドの集合を作る。 |
| §3.2、式(19)〜(23) | 各カテゴリの候補の中から、店全体の棚幅を配る。教材では2カテゴリとも採用する。 | model.js の choose |
| 線形化とSCIP | 著者が使ったソルバーや大きさの実験は再現しない。 | 架空の6 SKUで、候補をすべて調べられる規模の計算を行う。 |

出典は[出版社のPDF](https://dergipark.org.tr/tr/download/article-file/4435791)（[DOI](https://doi.org/10.17341/gazimmfd.1600434)）。2025年の論文である。初回の正確な公開日や著者の実装コードは、Labでは確認していない。

### 教材で直したのは、公開版の式の読み方である

式(2)の第2項では、式(1)を展開するときに残る代替率 s が印字にない。式(4)には s があるので、教材は式(1)と式(4)で揃えた。たとえば基礎需要が各10の商品を二つ用意し、単位粗利、面数、奥行きを1、採用費と補充費を0、代替率を0.5として一つだけ選ぶ。需要を直接計算した場合の利益は15、式(2)の印字どおりでは25になる。

式(5)では sTy の前にある三重の和を使わない。式(7)だけでは、商品を採用しないブランドを最低ブランド数に含められる。教材では採用した商品からブランドを数える。式(22)ではカテゴリと幅の候補について和を取り、式(21)で混在する棚幅の S と L は S に揃える。これらは公開資料の式に対するLabの解釈であり、著者のコードの誤りを示すものではない。

著者の線形化で使う補助変数 y と z は非負である。Labは初回の照合を r≤12 に絞り、単位粗利から1個当たりの補充費を引いた p−r/(fd) が全候補で0以上になるようにした。照合したのは直接式と式(4)から得る利益であり、著者の混合整数線形計画の解法ではない。

### 論文の計算時間は、前半と後半を分けて読む

著者は各カテゴリ内で商品と面数を選ぶ段階を18条件で試した（表2）。店全体で幅を配る段階は、50〜200カテゴリを含む16条件で0.10〜0.29秒だった（表3）。後半の時間には、前半で各カテゴリの候補を求める計算が入っていない。著者は小売企業にソフトを紹介したが、実店舗で棚を変えた後の売上や利益は報告していない。

### 関連する二つの記事との違い

[Whole Foodsの売場面積](whole-foods-shelf.html)では、著者は部門の面積を変えた場合の需要を見積もる。[Walmartの需要移転](walmart-demand-transfer.html)では、著者は品ぞろえを変えると需要がどの商品に移るかを推定する。この教材は、需要の反応を入力として与え、その条件で棚幅と商品構成を選ぶ。店舗で棚を変えたときの効果を測るものではない。
