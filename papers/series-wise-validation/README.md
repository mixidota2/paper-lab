# 学習に使わなかった系列を予測するときの検証

[原論文v1](https://arxiv.org/html/2611.08252v1)は、既存の系列だけを予測する場合と、学習に使わなかった系列も予測する場合で、モデルを選ぶ方法を比べています。時間で分ける検証がいつでも誤りという結論ではありません。

Labは10系列、各100点の合成例です。どの値で学習するか、どの値で選択するか、予測時にどの観測を入力できるかを分けます。論文の表3を使う集計は、この合成例とは別です。

## 再実行と配布

実行コードと補助ファイル（table3.json）を同じフォルダーへ保存してください。Python 3.10以上の標準ライブラリだけで動き、リポジトリ全体やuvは不要です。保存先で次を実行します。

```sh
python3 run.py --out series-cv-results.json
```

`--out` には既存の資料と重ならない名前を指定してください。既存ファイルを指定すると上書きします。省略すると `run.py` と同じフォルダーの `results.json` に保存します。

リポジトリの依存環境で検査やプレビューを行う場合は、ルートから次を実行します。

```sh
uv run --locked python papers/series-wise-validation/run.py --out /tmp/series-cv-results.json
uv run --locked pytest -q -ra --fail-on-skip tests/test_series_cv.py
uv run --locked python -m paper_lab.build --out /tmp/series-cv-preview
```

保存するJSONには、起点ごとの過去の観測時点、予測対象、予測値、実績と誤差、選んだモデル、共通尺度Qがあります。画面から保存すると、合成結果と論文の表の集計が別のキーに入ります。著者の実行ログではありません。

ブラウザーでダウンロードが始まらない場合も、JSON保存を押した後に表示される読み取り専用欄をコピーできます。条件を変える、不正な値を入力する、初期化する、のいずれでも欄は空になります。必要な結果は先に保存してください。

## Labで確認した範囲

学習と選択の時点、最終評価を選択に使わないこと、Q=0の表示、丸め済みの表の集計、保存したデータの再計算を確認しました。原論文全体の再現ではありません。著者の学習済み重みや実行環境を確認しておらず、実店舗、在庫費用、追加学習なしの時系列基盤モデルも試していません。DOMやCSSの検査は実ブラウザーの各画面幅での確認とは区別します。

## 計算が受け付ける入力

公開している主な入口は `evaluate()` です。A〜Jだけをキーとする辞書またはオブジェクトに、各100個の数値を格納します。Pythonではリスト、JavaScriptでは欠けた位置のない配列が必要です。各値は−1,000,000から1,000,000までの有限数です。文字列や真偽値、欠損、無限大やNaNは受け付けません。この範囲はLabの計算の制約で、論文データの制約ではありません。

Qは自動計算するか、0〜1,000,000の有限数を渡します。画面で手入力できるのは0〜100です。Q=0のMASEは定義せず、PythonではNone、JSONではnullにして、MAEを併記します。正のQが小さすぎて結果が有限にならない場合はエラーにします。NaNやInfinityをnullに変えて正常な値として返す処理ではありません。

`fit()`、`select()`、`predict()`、`scale_q()`、`origins()`、`role()` は、この合成例と検査に使う関数です。任意の入力向けのAPIではありません。`sensitivity()` も同梱の表3に限ります。Pythonは同梱JSONを読み、JavaScriptは同じJSON、掲載された手法名、Weatherを含めるかを内部で受け取ります。
