# 原論文とLabの対応

一次資料：[PDF v1](https://arxiv.org/pdf/2602.03338v1)。確認した論文内では公式実装へのリンクが見つからなかった。Labのコードは説明用に別に実装したもの。

| 原論文の箇所 | Labで見られるもの | 検証の範囲 |
|---|---|---|
| §1 式1–4、付録D | `accounting`、式と2×2の結果表 | 課題ごとに介入なしとありの最終結果を比べる。途中の介入回数は数えない |
| §3 表1–2 | 失敗予測器の説明 | AUROC 0.936は著者報告。Labは予測器を学習していない |
| §4 表4、付録A 表17 | 成功率が26ポイント下がった例と2.8ポイント上がった例 | モデル、評価課題、介入方法が異なる |
| 図1、§4・7 | `simulate_pilot`、導入判断の図 | 介入なしの失敗率0.89、失敗を回復する確率0.12、成功を崩す確率0.56を仮定した。論文の実行記録は入手していない |
| §4と付録D・G | 本文と表の不整合の説明 | 回復件数と失敗に変わった件数の比と、それぞれの割合の比を分け、式1–4を採用した |
| §5.5 表10 | 成否が分かると仮定した場合の比較 | 失敗の予測や2回の結果からの選択を誤らないと仮定した上限。実装で達成した性能ではない |
| §8、付録C | 限界と50課題の人工試験で観測した差の分布 | 論文のブートストラップによるp値や区間推定は再現していない |
