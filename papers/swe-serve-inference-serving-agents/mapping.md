# 論文とLabで確かめられる範囲

[論文の初版（arXiv:2609.26777v1）](https://arxiv.org/pdf/2609.26777v1)を参照しました。保存したPDFのSHA-256は `891301e2e96052899a86ca99966fb805d29c50e63b1fadc9fe9517769b1cd4e0` です。

| 論文が検査するもの | Labで確かめるもの | Labでは扱わないもの |
| --- | --- | --- |
| 参照実装と変更前の版で採点条件を確かめる（§3、図1） | `run.py` は、変更前も含む4つの架空の変更を3種類の検査にかけます。 | 実コンテナ、採点用の非公開テスト、GPU |
| 推論サーバーの53課題を6分野に分ける（表2） | 記事の表は分野ごとの課題数を示します。 | 各課題の実装 |
| 実モデルを動かす検査を採点から外す（§5.2、図2） | 記事は著者が公表した件数を説明します。画面の例は4つの架空の変更だけを扱います。 | 論文の627件の変更を実行して採点すること |
| 同じモデルを別の実行支援で比べる（§5.3、付録A.5） | 記事は、著者の比較結果と、この比較だけでは言えないことを書いています。 | 実際にエージェントを動かして比較すること |

論文にはコード公開の記述がありますが、Labは対応する配布先を確認していません。SGLangのリポジトリは、SWE-Serveの採点プログラムとは別です。Labの小さな配信プログラムは、原著の実装を移したものではありません。
