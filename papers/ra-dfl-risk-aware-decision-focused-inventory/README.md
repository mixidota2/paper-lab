# RA-DFL：在庫配分の費用を見ながら需要予測を学習する

著者は、限られた在庫を複数の販売チャネルに配るとき、需要予測の誤差ではなく、その予測で在庫を配った場合の費用を使って予測モデルを学習しました。RA-DFLは平均費用と、費用が特に高くなる場合の損失の両方を考慮します。また、欠品で売れなかった分が売上に表れないため、観測売上をそのまま見て在庫を余らせたと判断しないよう、学習時の費用を補正します。

著者がM5のデータで計算した平均費用は、LightGBMで需要を予測してから配分する方式で4.903、RA-DFLで4.721でした（3.7%減）。一方、LightGBMの予測はそのままで、配分だけに高費用時のリスクを加えると5.380になりました（9.7%増）。RA-DFLが別の評価データでも勝ったわけではありません。評価では観測した売上を需要の代わりに使い、販促や欠品も代理指標で判定したため、実店舗での費用削減を測った結果ではありません。

## 問題設定

在庫容量を共有する複数のチャネルが、同じ商品を売ります。担当者はチャネルごとに置く量を決め、需要が分かってから、余ったチャネルの商品を足りないチャネルへ移せます。論文は、販促中に品切れした場合に大きい費用を割り当てます。

売れる在庫がA個しかないと、需要DがA個を超えても販売数yはA個です。販売数y=min(D,A)を需要だとみなして費用を計算すると、実際には売れたはずの在庫を余剰として扱う場合があります。

## 配分費用を使う学習

著者は、商品と地域で共有する在庫を配るため、需要の分位点と配分に使うリスクの重みを予測します。配分を計算した後の費用から予測モデルを更新し、欠品と判定したときは観測売上を超えた配分に余剰の罰則をかけません。

基準の予測を変えずに費用が高い場合を考慮する配分だけを加えると、平均費用は上がりました。どの需要を観測できたかで結果の読み方も変わります。著者の比較は観測売上と代理指標を使っており、実店舗にそのまま導入できることを示していません。

## 需要予測と在庫配分を学ぶ手順

比較対象のLightGBM-QRは、需要の分位点を先に予測し、その予測で在庫の配分を決めます。著者はこの手順をPTO（Predict Then Optimize）と呼びます。RA-DFLでは、別の予測モデルである多層パーセプトロン（MLP）を使います。まず分位点を学習し、次に配分の結果から求めた費用を使い、配分を計算する処理を通して予測モデルを更新します。LightGBMをこの学習に組み込むわけではありません。

| 段階 | 論文で行うこと | Labで行うこと |
| --- | --- | --- |
| 需要を予測する | MLPが需要の20個の分位点と、リスクの重みを決める値を出します。 | 予測せず、固定した需要を使います。 |
| チャネルの需要を組み合わせる | 需要が連動するようガウシアンコピュラを使い、32シナリオを作ります。 | 同じ確率の10シナリオを使います。 |
| 配分を決める | 平均費用、CVaR、目標の充足率を下回る罰則を合わせて、連続量を配ります。勾配の方向を求め、候補の一歩を比較し、容量内に収めます。 | 容量に収まる整数配分66通りを比べます。充足率の罰則は入れません。 |
| 配分の結果から予測器を更新する | 欠品時の余剰罰則を外した費用と、分位点を学ぶ片側のピンボール損失を使います。 | 予測器は学習せず、移送がない場合に余剰罰則を外す効果を別の例で計算します。 |

### 配分するときの重みと、学習全体の重み

CVaRは、費用が高い方から決めた確率分を取り出して平均した値です。Labでは高い方の20%を使います。境界に同じ費用が並ぶ場合も、その確率幅に合う重みを使います。論文の配分では高い方の10%を使い、商品・地域の在庫グループと期間ごとに、予測モデルが出す `w_i` で平均費用との比重を変えます。一方、予測モデルを学習するときは、訓練事例全体の費用に固定の `w_out=0.3` を使います。どの事例でリスクを重く見て配分するかと、学習全体で高費用をどの程度避けたいかは別です。Labの図で動かすのは配分の重みだけです。

### 余った在庫を移す条件

在庫移送は、余ったチャネルから足りないチャネルに商品を移すことです。Labの設定では、1個移すと保有費用1と欠品費用6を避け、移送費用1を払うため、合計費用が6下がります。したがって、余剰と移送を受け入れる需要の範囲内で、移せるだけ移します。

論文の命題1は、移送単価が一律なら移せる最大量を移すと述べます。しかし、式(2)では移すかどうかを選べるので、単価が一律という条件だけでは足りません。配分が(2,0)、需要が(0,2)、保有費用1、欠品費用6、移送可能率0.4、移送単価8なら、移さないと費用14、上限の0.8個を移すと14.8です。この反例は、単価の条件が必要なことを示すだけです。Labの本計算は移すたびに費用が下がる設定に限ります。

論文の§4.2にある比率を、同じ仕入れ単価を基準とする二つのチャネルに当てはめても、一律の移送単価で最大量を移す方が常に安いとは言えません。販促していない受け手では、保有費用と欠品費用の合計が仕入れ単価の約0.1333倍で、移送費の0.15倍を下回ります。受け手が販促中なら、欠品費用が1.5倍になり、合計は0.19倍になります。実際にチャネルの費用の基準が同じだったか、評価で式(2)を解いたか式(3)を使ったかは確認できず、著者報告への影響は分かりません。

### 売上を補正しても真の需要は分からない

式(5)では、欠品と判定したチャネルについて、観測売上を上回る配分にかかる余剰罰則を外します。移送を行わず、真の需要が10、売上が4なら、配分が4以上のとき、補正後の損失はどの配分でも0になります。これで観測売上だけから余剰だと誤判定しなくなりますが、真の需要が10だったとは分かりません。

命題2の補正後の損失が真の費用以下でも、最小にする配分まで一致するとは限りません。移送なし、容量4、真の需要(3,3)、売上(1,3)、チャネル1だけが欠品とします。保有費用は両方1、欠品費用は順に6と2です。補正後の損失は(1,3)で最小の0ですが、そのときの真の費用は12です。真の費用は(3,1)で最小の4になり、この配分での補正後の損失も4です。整数配分をすべて比べた例で、論文の分位点の損失を足した学習全体や、移送がある場合の命題を検証したわけではありません。

## 費用で予測を学ぶ理由

同じだけ予測が外れても、在庫を置けなかった先や費用によって影響は異なります。配分後の費用で予測モデルを学べば、配分で問題になりやすい誤差を重く扱えます。ただし、著者がすでにある予測にCVaRを考慮する配分だけを足したときは、平均費用が上がりました。

著者は欠品と判定したチャネルで余剰の罰則を外し、売上より多く置いたことだけで過剰と扱わないようにしました。ただし、罰則を外しても売れなかった需要は観測できず、補正後の損失と真の費用を最小にする配分が一致するわけではありません。

## 論文の評価結果

一次資料は[出版社PDFの§4.4、表II〜VII、図1](https://hbemdata.org/index.php/ojs/article/download/198/176/352)です。以下は著者報告で、Labが再計算した実験結果ではありません。M5では観測売上を需要に置き換え、値下がりから販促を、売上ゼロの日が続くことなどから欠品を判定しました。Stallionでは販促を直接観測しています。在庫容量も費用も論文の設定であり、両データで実店舗の在庫運用を変えたわけではありません。

| M5の方法 | 平均費用 | グループ別CVaRの平均（CVaR_pool） |
| --- | --- | --- |
| LightGBM-QRで予測してから配分（PTO） | 4.903 | 13.70 |
| 同じ基準予測にCVaRを使う配分を追加 | 5.380 | 14.36 |
| DFL-EV | 4.690 | 14.11 |
| RA-DFL | 4.721 | 13.67 |

CVaR_poolは、同じ商品・地域で容量を共有するグループごとに、期間別費用の高い方10%を平均し、その値を全グループで等しく平均します。一方、CVaR_weekは、期間ごとに全グループの費用をまず足し、その合計が高い方20%を平均します。M5なら1期間は1週ですが、Stallionでは1か月です。個々の事例の高い方5%を表すCVaR₀.₉₅も別の指標です。13.70から13.67への変化は相対で約0.2%減であり、百分率のポイント差ではありません。

M5の1回の実行では、DFL-EVの方がRA-DFLより平均費用が低く、CVaR_poolは高くなりました。乱数の初期値を変えた3回では、平均費用はRA-DFLが4.722 ± 0.002、DFL-EVが4.729 ± 0.034でした。±は標本標準偏差で、信頼区間ではありません。これだけでどちらの平均費用が低いかを断定できません。また、本文はRA-DFLの充足率が学習法の中で最高としていますが、表IIではLightGBM-QRが92.85%、RA-DFLが92.78%です。ここでは表の値を使います。

Stallionの平均費用はRA-DFLが48.4千、LightGBM-QRが48.2千、DFL-EVが47.8千でした。DFL-EVはRA-DFLよりCVaR_poolも低く、RA-DFLはCVaR_weekでわずかに低い値でした。MLPで先に予測した後、同じ予測にCVaRを使う配分を追加した比較では、平均費用が50,054から55,665に約11.2%増えました。この11.2%はLightGBM同士の比較ではありません。

欠品補正を外すと、M5では平均費用が4.721から4.776に増えました（p=0.003）。Stallionでは差を確認できませんでした（p=0.25）。表Iの欠品判定はM5が12.3%、Stallionが1.3%で、§5.8はStallionを1.4%と記載しています。いずれも代理指標で判定した割合で、真の欠品率ではありません。参考文献[43]〜[46]の他分野の事例は、これらの在庫実験を独立に裏づけるものではありません。

## 図で確かめること

配分図では、総容量10を二つのチャネルに配ります。保有費用1、欠品費用6、移送費用1、移送可能率0.4を固定し、同じ確率の需要10シナリオで整数の配分66通りを比べます。配分に使う重みwを動かすと、平均費用と費用が高い方20%の平均（CVaR₀.₈）をどれだけ重く見るかが変わります。論文の予測モデルや学習全体の重みは再現していません。

欠品補正の図は別の人工例です。移送を行わず、真の需要10に対して売上が4だったとします。売上を需要として計算した損失と、欠品時に余剰の罰則を外した損失を比べます。図には比較のため、真の需要で計算した費用も描きます。

## Labの人工例

平均費用だけを使うw=0では、(4,5)、(5,4)、(6,3)がいずれも9.88で最小です。図は同点を決める既存の規則で(4,5)を表示します。一つだけ最適という意味ではありません。図で選べるw=0.25、0.5、0.75、1では、(4,6)を選びます。平均費用は9.96と少し上がりますが、高い方20%の平均費用は20.0から18.4に下がります。

欠品補正の図では、配分を売上の4より増やしても、補正後の損失は0のままです。真の需要が10だったとは分かりません。Labは真の需要・売上・配分を変えた1,456通りで、移送がない場合に、補正後の損失が真の費用を超えないことを確認しました。別の計算では、移送単価が高いと移さない方が安く、補正後の損失を最小にする配分が真の費用で最適とは限らないことも確認しました。条件と数値は手法の説明にあります。

## 確認したこと

CONFIRMED（確認済み）：Labは、有限個の需要シナリオで平均費用とCVaRを計算し、容量内の整数配分をすべて比べました。移送がない場合に限定し、補正後の損失が真の費用を超えないことを検算しました。

PARTIAL（一部確認）：Labは配分で高費用時を重視する効果と、欠品時に余剰罰則を外す効果を別々に確かめました。命題1の反例は移送単価が高い特定の条件、命題2の最小値の反例は移送がない整数配分に限ります。学習全体や移送を含む一般の関係は確認していません。

## 確認していないこと

NOT TESTED（未検証）：LabはM5やStallionで学習し直していません。連続配分を求める層の平均最適性ギャップ0.32%、基準比3.7%の費用低下、CVaRだけを追加した9.7%の増加は著者報告であり、Labは再現していません。実店舗の在庫・費用や、Chronosなどの時系列基盤モデルと決定木系モデルとの優劣も検証していません。

リポジトリの直下で次を実行すると、Pythonの標準ライブラリだけで `results.json` を作り直せます。乱数、外部データ、GPUは使いません。

```bash
UV_CACHE_DIR=/tmp/uv-cache uv run --no-project papers/ra-dfl-risk-aware-decision-focused-inventory/run.py
```

`run.py` が費用と配分を計算し、`paper_lab/inventory02.py` が図を描きます。サイトは `lab.yaml`、`method.md`、`mapping.md` と計算結果から表示を作り、`README.md` にも読み方と手順を載せています。著者の実装は動かしていません。

サイトも作り直す場合は、リポジトリの直下で次を実行します。

```sh
UV_CACHE_DIR=/tmp/uv-cache uv run paper-lab build
```
