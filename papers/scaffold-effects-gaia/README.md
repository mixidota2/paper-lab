# 同じモデルでも、エージェントの進め方で正答率は変わるか

著者は、GAIAの同じ問題を、5つのモデルに3種類の進め方で解かせた。Claude Opus 4.7 の難易度2では、特定の実行エラーを除いた集計で、最も良い進め方と最も悪い進め方の正答率に28ポイントの差があった。すべての試行を数えた場合の同じ差は14ポイントだった。[論文の本文と表](https://arxiv.org/html/2606.08529v1)

Lab では、条件をそろえて2つの方法を比べるとき、どの単位で結果を数えるかを小さな作例で確認する。論文のモデルや GAIA は実行しない。配布する数値は作例の計算結果で、論文の正答率、料金、エラーからの回復率ではない。

リポジトリ直下で実行すると、作例の結果を更新し、Lab のページを作る。

```bash
uv run --locked python papers/scaffold-effects-gaia/run.py
uv run --locked paper-lab build
```

`method.md` は3種類の進め方と集計条件を説明する。`results.json` は作例の結果を収める。図は構成や測り方を説明するためのもので、数値を示す論文の図とは別だ。

再試行の上限は初回呼出しを含まず、失敗後に何回やり直せるかを表す。成功したタスクはそこで止める。上限を1回にすると、完了件数は15件から30件になり、ツールの呼び出しは60回から105回になった。どの試行で成功するかは、Lab があらかじめ決めた。
