# Hard Constraints, Smooth Gradients: Learning Feasible Inventory Policies via Differentiable Projection

## Overview — 設備を分け合う製品の生産量を決める

複数の製品で設備や資材を分け合うときは、製品ごとの生産量を別々に決めると、全体の上限を超えることがあります。著者は、学習モデルが出した目標を上限内の近い値に移し、整数の生産量に直す方法を提案しました。学習時は整数化を通る勾配を近似し、将来の在庫費用から生産目標の出し方を学びます。

論文の改訂版では、ASMLの研究課題をもとに14品目の生産と在庫をシミュレーションしました。予測に応じて在庫目標を変える最良の比較手法に対し、平均費用は基本設定で0.9%、設備容量が厳しい設定で1.8%低くなりました。これは実際の工場で生産計画を変えた結果ではありません。初版とは評価の条件が違うため、数値を区別して紹介します。

## Problem — 製品別に上限を守っても、設備全体では超えることがある

多段階の生産計画では、製品ごとの上限を守っても、全製品で同じ資材や設備を使い過ぎることがある。すべての製品の生産量をまとめて決める必要がある。満たせなかった需要は、次期以降に届ける注文（バックオーダー）として残す。欠品でその場の売上を失う小売モデルや、食品売場の棚割りを無作為化して効果を測る試験（RCT）とは別の設定だ。

## Core Idea — 制約内の近い点に移してから整数にする

【著者の主張】ニューラルネット（NN）が出した連続値の生産目標を、強凸二次計画（QP）で制約内の近い点に移す。次に、その制約の厳しさを表す双対価格を使って整数にする。学習時は射影の解析Jacobianと、整数化を通る勾配を近似するSTEを組み合わせ、微分可能なシミュレーターの費用からNNを更新する。

【Labの解釈】DeepStockが在庫の構造を手がかりに方策を探すのに対し、この研究は複数製品で共有する資材や設備の上限を、各期の整数の生産判断に直接反映する。Constrained FBSDEが在庫などの時間変化を制約するのとは、守る対象が異なる。性能の優劣を比べたわけではない。

## Why It Might Work — 共有上限に達すると、片方を増やすにはもう片方を減らす

【Labの解釈】勾配には、目標を少し変えたとき、実際に選んだ量がどの方向に動くかが表れる。上下限から離れているFreeでは目標どおりに動く。製品1が個別上限に達したPinnedでは、その量をこれ以上増やせない。2製品で共有上限に達したCompetingでは、製品1を増やすには製品2を減らす。

著者の補題1では、資材残量などで上限が変わる場合、目標側では失われた方向の情報が、制約式の右辺bへの勾配に現れる。残量を変えた過去の判断にも学習信号を返せる。固定容量にはこの補償がない。等号になっている制約の組（活性集合）が切り替わる点で、通常の微分が常に存在するという主張でもない。

## Executable Understanding — 2製品で射影と整数化を試す

2製品の目標をz、生産量をxとする。x₁≥0、x₂≥0、x₁≤3、x₁+x₂≤6を満たす多角形の中から、zに一番近い点を選ぶ（射影）。重みはW=diag(1/2,1/2)。すべての辺の最近点を調べて厳密解を選ぶので、外部QPソルバーは不要。制約のかかり方を3通り選び、連続出力をどれだけ動かすかを表す解析Jacobianを、目標を両側にわずかに動かす中心差分と照合する。

次に§4.1.2に沿って、小数点以下を切り捨てた量（floor）から始める。双対価格を使った優先順位で、各製品の量を1単位だけ増やせるか調べる。制約を守り、目標からのずれを評価する目的関数を悪化させない増分だけを採用する。6,561個の目標を同条件でfloorと比べ、すべての整数点を調べた解とも照合する。図5に対応する別実験では、x₁+x₂≤2の下で(1,1)を選ぶ目標の範囲を調べる。

## Results — 切り捨てとの違いを数える

6,561個の目標のうち、整数化した後の制約違反は0件。3,915件で単なる切り捨てより目的関数の値が改善した。この2製品の設定では、すべての整数点を列挙した最適解との差も0だった。整数写像は一般には近似であり、この一致は一般の整数QPでは保証されない。

図5の縮約では、1,600個の目標のうち、切り捨てで(1,1)になったのは0件、提案の整数化では1,600件だった。(1,1)に写る目標が面積を持ちうる例で、論文の完全性定理の証明ではない。完全性は、各整数行動に写る目標の集合が、単に空でないだけでなく、Lebesgue測度で正の大きさを持つ条件を指す。

## What We Verified — 縮約した計算で一致を確かめた

**CONFIRMED — 局所計算**：Free／Pinned／Competingの各例で、Jacobianが中心差分と一致した。全サンプルの整数行動が制約を守り、切り捨てよりも目的関数を悪化させないことをassertで確かめた。

**PARTIAL — 一部だけ実装**：QPによる射影と整数化を2製品に縮約した。NN、経路微分による方策学習（HDPO）、整数化を逆伝播するときに恒等写像とみなすSTEは、学習実験に含めていない。

## What We Did NOT Verify — 長期費用と学習効果は未再現

**NOT TESTED**：多段階在庫の長期費用、小規模の最適性ギャップ0.91%、ASMLの費用削減、規模を大きくしたときの挙動、現場導入。STEは真の微分を計算しないため偏りがあり、学習にどれだけ有効かは未検証。一般制約での完全性や誤差の上限は論文の主張として紹介する。
