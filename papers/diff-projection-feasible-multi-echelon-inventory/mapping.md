# 原論文の版とLabの実装の対応

[初版（v1）](https://arxiv.org/abs/2608.02343v1)の提供PDFの§4〜6、図3〜6、表1〜5を確認しました。以下のうち、図と著者の費用の再掲は初版に基づきます。[改訂版（v2）](https://arxiv.org/html/2608.02343v2)の表5・6は、本文で初版と分けて紹介しています。

| 原論文 | Labで読む場所 | Labで再現していないこと |
| --- | --- | --- |
| v1 §4.1.1、式(2)、図4 | `run.py` の `project()` と2製品の射影図で、制約内の連続解を計算します。 | 一般次元の二次計画、重みの変更、制約の分解。 |
| v1 補題1・系1 | 3つの例で連続解の勾配を計算し、中心差分と比べます。 | 制約の右辺への微分、等号になる制約が切り替わる点での微分。 |
| v1 §4.1.2 | `integer_map()` で双対価格による優先度を計算し、容量内かつ目的値を悪化させない増分だけを採用します。 | ニューラルネットワーク、経路微分での方策学習（HDPO）、STE。 |
| v1 定義1、図5 | 共有上限2の人工例で、整数解(1,1)に写るかを比べます。 | 完全性の一般の証明、すべての制約や重みでの検証。 |
| v1 表1・2・4・5 | 著者報告の表と、表4の設定1の費用内訳を示します。 | 小規模問題やTempelmeier型ネットワーク、ASMLの研究課題での費用再計算。 |
| v2 表5・6、§6.4〜6.5 | 改訂版の比較と、整数化や勾配を変えたときの差を本文に載せています。 | 新しい条件の需要経路、信頼区間、学習の再現。 |

図は論文の式と報告値からLabが作りました。提供PDFでは公式コードへのリンクを確認できず、Labは著者のコードを実行していません。

関連研究との関係はLabの整理です。[Constrained FBSDE](constrained-deep-inventory-fbsde.html)は在庫などの状態の推移を制約し、[DeepStock](deepstock-policy-regularized-inventory-drl.html)は在庫の関係式を強化学習に組み込みます。OR-Transformerとも、同じ条件で性能を比べていません。
