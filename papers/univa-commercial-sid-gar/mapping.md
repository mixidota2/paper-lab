# 原論文と実装の対応

一次資料は[第2版のPDF](https://arxiv.org/pdf/2605.05803v2)。Labは論文中に公式実装へのリンクを確認できなかった。以下の実装は、論文の一部を説明するためにLabが用意した。

| 原論文の箇所 | Labの対応 | どこまで確認したか |
|---|---|---|
| 第2版 §3.1、式1–8、付録C/F.1 | 商用識別子の構成図と `run.py` の `tokenize`、`dispersion` | Labは属性を2群に固定し、群ごとに2区間へ分けた。語彙のエントロピーを最大化する処理は実装していない。 |
| 第2版 §3.2、式15–16 | GARの式とビーム探索 | Labは固定の生成ロジットに固定の価値スコアを足した。ニューラルモデルは学習していない。 |
| 第2版 §3.3、付録B | 手法の説明 | LabはPPO・MCTS・eCPMを論文で確認したが、実行していない。 |
| 第2版 §3.4、式21–24 | 探索候補から無効な枝を除く処理 | Labは人工の探索木で、除外の時点によって同じ候補の対数確率と探索結果が変わることを確認した。 |
| 第2版 §4.4 | 有効な識別子の経路数を比べる図 | 48経路と300経路は著者の報告値。Labは本番の比較を再現していない。 |
| 初版 表3、第2版 表4 | 実験に使った本番トラフィックの割合の比較 | 初版は5%、第2版は20%と記載する。変更の理由は本文からは分からない。 |
| 第2版 表2、付録F.1 | 構成を順に追加した比較の図 | 完全構成ではデコーダの容量も増える。従来の広告配信の工程をすべて取り除く比較ではない。 |
