# DREAM：既存の推薦モデルを残し、買い物の意図に合わせて設定を変える

TaobaoのDREAMは、利用者が長く持つ好み、そのときに必要な商品、価格やブランドなどの条件を分けて扱います。DREAMは買い物の意図をもとに変更の方針を作り、各段階の変換処理が実際の設定に直します。既存の推薦モデルや並べ替え処理はそのまま使い、変更できる設定だけを調整します。

Taobaoのホーム画面のA/Bテストで、著者は最後の並べ替えを調整した構成では、商品詳細ページへの訪問が従来方式より2.06%増えたと報告しました。詳しい順位付けにも調整を加えた構成では、同じ従来方式より2.71%増えました。この二つは共通の基準との比較で、足し合わせる数字ではありません。人間とエージェントに同じ条件で改善策を探させた試験でもありません。

一次資料：[著者論文第3版](https://arxiv.org/pdf/2608.09408v3)。

## 何を変え、どこに戻すかを読む

[method.md](method.md)は意図を推定する処理、方針を設定値へ変換する処理、本番の反応を学習に使う処理を分けて説明します。[mapping.md](mapping.md)では、論文の図表とLabが実行した部分を確認できます。記事と図は `lab.yaml` などから生成します。

## 人工例を実行する

リポジトリのルートで次のコマンドを実行します。`run.py` はPythonの標準ライブラリだけで動き、結果を同じフォルダの `results.json` に保存します。

```bash
uv run papers/dream-taobao-agentic-control/run.py
uv run paper-lab build
```

Labは、決めた形式を満たす方針なら一部の設定だけを変え、期限切れや無効な値なら既定値を使うことを確認しました。呼び出し枠を使い切った場合や、記録の再生で二つの方針が同点だった場合も人工条件で試しました。これらの結果はLabが用意した設定に限ります。

Labは端末のGRUやIntent Agent、Qwen3を使った学習、記憶の更新、実サービスでの再生を実行していません。方針の質、期限の最適値、端末の費用、本番での改善も測っていません。一部の入力を既定値に戻せることは、本番全体の安全を保証しません。著者の公式コードへのリンクは、確認した資料では見つかりませんでした。
