# 論文とLabで確認した処理の対応

[論文第3版](https://arxiv.org/pdf/2608.09408v3)のどの処理をLabで説明・計算したかを示します。元のPDFは2026年9月18日に確認しました。PDFのSHA-256は `aa7c9bfe3ce9cc28ceb03854a5390a5ed268e5bffd166857e6827ce44e55319a` です。公式コードは確認できなかったため、Labのコードは論文のしくみを説明するために別に作りました。

| 論文の箇所 | Labで扱う内容 | 検証の範囲 |
|---|---|---|
| §3、表1、図3〜5 | 利用者の意図を三つの階層で扱う図と、報告を絞る図 | ニューラルモデルは実行しません。約15%、約8.7%、約6.3%は分母の異なる著者報告です。 |
| §4.1、式5〜15 | `invoke()` で呼び出しを判定する人工例 | 所与の点を閾値と比べ、呼び出し枠が残っているかを確認します。実運用の値ではありません。 |
| §4.2、表6、式16〜19、図7 | `compile_strategy()` で方針から設定値を求める人工例 | 一部の項目だけを扱い、期限や重みにはLabが決めた値を使います。 |
| §4.3、式20〜25、図8 | `replay_reward()` で二つの平均点を比べる | 提案の平均が高い場合だけ1になります。同点は0です。サービスへの要求は送っていません。 |
| §5.1、表7 | A/Bテストで報告された増加率を比較する | 共通の基準に対する値を比べます。追加効果の因果推定や有意差検定は行いません。 |
| 付録B、表11 | 4BのMetaModelを対象にした記録再生の代理評価 | 著者報告を説明します。学習や同じ評価は実行していません。 |

式13は文章で説明される信号数と、式に書かれた項の数が一致しません。Labは書かれていない項を補っていません。また、M3は変換処理が決める設定値です。LLMが直接書いた設定として扱いません。
