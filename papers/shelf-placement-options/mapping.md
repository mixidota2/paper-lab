## 著者のモデルのうち、この教材で試したこと

一次資料は [出版社の本文](https://journals.sagepub.com/doi/10.1177/10591478251359808) と [著者の大学が公開したPDF](https://edoc.ku.de/id/eprint/35545/1/zajac-kuhn-2025-joint-shelf-design-and-space-planning-problem-with-placement-options.pdf) です。ZajacとKuhnの論文は2025年にオンラインで公開され、巻号は2026年です。原典はCC BY 4.0。教材の図は、原論文の図を写さず、検査した合成座標から描きます。

| 原典 | 教材が行うこと | 教材で置く条件 |
|---|---|---|
| 式(1)〜(4) | `toy_a` と `toyA` が置き方と面数から需要を計算する | 棚置きの1面需要は12×2/3=8。高さ比に取り出し余白は入れない |
| 図3 | 余白を含めて長方形が使う高さを計算する | 吊りはb(3+ν)、棚置きは2b。同じSKUを積む間に余白を取らない |
| 式(9)〜(14) | `run.py` の `check` が候補の座標を調べる | 商品の重なりと枠からのはみ出しは不可。辺の接触は可 |
| 式(19)〜(24) | 棚板上面、板厚、商品を支える面を確かめる | 全幅を使う2商品に、追加棚板1枚を使用 |
| 式(32)、(34) | 配置可否には使わない | 単位と添字の注意は `implementation.md` を参照 |
| 複数の初期案から始める探索と補足設定 | 再現しない | 不明な設定値を推測で補わない |

著者は欧州の食品小売会社から非食品237商品・6カテゴリの商品情報と既存の棚割りを受け取りました。利益率は仮定した分布から引き、5店舗分の販売もシミュレーションしています。表12の平均4.0%は、既存案と新しく計算した案をモデル上で比べた差です。別の平均0.6%は、同じ模擬販売を使って店舗別の案を共通案と比べた差です。比較相手が異なるので二つは足せません。店舗で棚を変更して売上や利益を測った結果ではなく、Labの合成例も著者の事例を再現していません。

対応表はレビュー仕様と原典の関連箇所を基にしました。本文の全式・全図や補足資料の設定は独立に照合しておらず、著者が公開表記どおりに実装したかも不明です。

`check(layout, spec)` は候補座標とは別に商品定義を受け取り、必要なIDが過不足なく並ぶか、許可された方法か、整数の面数と上限・寸法が定義どおりかを調べます。座標で支持面、板厚、取り出し余白も検査します。同じ処理を画面で生成した候補にも適用します。棚板を可変にした案には、固定案と同じ棚板高も候補に残ります。

[品揃えと補充](assortment-replenishment-hard-constraints.html) は、どの商品を採用するかも決めます。この教材では全商品を置き、価格、在庫、代替需要、補充費は最適化しません。
