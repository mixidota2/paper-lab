# 原論文と実装の対応

一次資料は [原論文 v1](https://arxiv.org/abs/2609.28383)。確認には、提供された PDF とそこから抽出したテキストを使った。PDF のハッシュは lab.yaml に記録した。公開ページの HTML は lab.yaml、README.md、method.md、run.py、results.json から生成する。

原論文は、動画の長さが分かっても平均視聴時間だけでは完了や overplay の確率は分からないと指摘する。Lab の最小実装では、論文のモデルを学習せず、説明用に作った分布でその違いを確かめる。

| 原典 | 本 Lab の対応 | 省略・境界 |
| --- | --- | --- |
| Fig. 1、§3.1 | 同じ長さで平均視聴時間も同じ二群を比べる | 二群は説明用に作った。実データの分布ではない |
| Fig. 2、Eq. 4 | `run.py` の `state()` が、視聴時間を動画長で割った値で四状態に分ける | 状態を分ける境界は論文と同じ |
| Eq. 5–6 | `support` が各状態で取りうる時刻を示し、`masked_mass` がそこだけに確率を割り当てる | 0〜20秒の格子で確認する。論文の69個の時間区間で学習する処理はない |
| Eq. 7、9–10 | `summarize()` が平均視聴時間、各状態の確率、long の確率、状態のエントロピーを計算する | 論文が要約する統計量の一部だけを扱う |
| Eq. 8 | `lab.yaml` で、分布の平均を記録された視聴時間に近づける復元損失を説明する | 復元損失でモデルを学習していない |
| Eq. 11–14 | 分布の要約から視聴秒数を予測し、順位を付ける読み出しの式を説明する | DCNv2 の読み出し層は学習していない |
| Table 1、Fig. 3、Table 2 | README の Evidence 節に、精度の比較と、読み出し層をそろえた比較を記す | 著者の実験結果を紹介している。Lab で再現した結果ではない |
| Appendix E、Table 9–10 | README の Why It Might Work 節に、四状態を明示しない分布の要約でも成績がほぼ同じだった対照を記す | 四状態に分けること自体の優位性は、この対照からは言えない |
| §4.4、Table 3–4 | 別の視聴目標や、視聴時間とは別に記録された行動への転用を説明する | 転用実験は実施していない |

論文の1ページ目には [公式コード](https://github.com/Xuanxuana1/DSI) へのリンクがある。Lab では公式コードのファイルと論文の対応は調べておらず、実行もしていない。この教材の最小実装は公式コードの抜粋ではない。

原論文には本番 A/B テストの結果がなく、事業への効果は未確認である。
