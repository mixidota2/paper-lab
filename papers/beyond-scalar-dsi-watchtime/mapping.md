# 原論文の式とLabの合成例

出典は[arXivの第1版](https://arxiv.org/html/2609.28383v1)です。[書誌ページ](https://arxiv.org/abs/2609.28383)には版の情報があります。Labは提供されたPDFと抽出テキストを確認し、PDFのハッシュを `lab.yaml` に記録しました。公開ページは `lab.yaml`、`README.md`、`method.md`、`run.py`、`results.json` をもとに生成します。

| 論文の箇所 | Labで何を確かめるか | Labが扱わないこと |
| --- | --- | --- |
| 図1、§3.1 | 合成例では平均と動画長が同じ二群で、終了付近まで見る確率が変わります。 | 二群の割合はLabが決めました。実データから推定していません。 |
| 図2、式4 | `run.py` の `state()` は視聴時間を動画長で割り、四つの状態に分けます。 | 状態の境界には論文の値を使います。この区分で満足度や意図を測りません。 |
| 式5〜6 | `support` が各状態で取り得る時刻を列挙し、`masked_mass` がそこにだけ確率を置きます。 | Labは0〜20秒を1秒刻みにした例を使います。論文の69区間でモデルを学習しません。 |
| 式7・9〜10 | `summarize()` は平均秒数、各状態の確率、終了付近と110%超を足した確率、確率のばらつきを計算します。 | 論文が使う27個の値の一部だけです。 |
| 式8、式11〜14 | 記事の式では、分布の平均を記録された秒数に近づける学習と、秒数・順位の予測を分けて説明します。 | 復元損失を使った学習や、DCNv2での順位付けは実行していません。 |
| 表1、図3、表2 | 記事の根拠の節では、全方式を比べた結果と、後段のモデルをそろえた結果を分けています。 | 著者が報告した値であり、Labは公開データで再計算していません。 |
| 付録E、表9〜10 | 記事では、時間だけで学んだモデルや視聴状態で区分しない要約でも、成績が近かった比較を説明します。 | 四つの状態に分けること自体の効果は確定していません。 |
| §4.4、表3〜4 | 著者は、固定した分布を別の視聴指標や「いいね」などに使えるかを調べました。 | Labは転用実験や本番の比較をしていません。 |

著者は[公式コード](https://github.com/Xuanxuana1/DSI)を公開しています。Labは公式コードと論文の対応を調べたり、実行したりしていません。配布するコードはこの合成例のために作ったもので、公式実装からの抜粋ではありません。
