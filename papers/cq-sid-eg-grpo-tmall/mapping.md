# 原論文と実装の対応

一次資料：[PDF v1](https://arxiv.org/pdf/2605.14434v1)。公式実装へのリンクは確認した論文では見つからなかった。以下の対応表は論文の手法を説明するためにLabで作った実装について示す。公式コードとの対応表ではない。

| 原論文の箇所 | Labの対応 | 確認の範囲 |
|---|---|---|
| §3.1、式1–7 | method、量子化の式 | RQ-VAE/EMA/InfoNCEは説明のみ |
| Algorithm 1 | run.py split_cluster | 分割した群ごとの件数だけを均等にする。各商品を無作為に割り当てる処理は省略 |
| §3.2 | 学習段階の本文 | Qwen2.5-0.5Bを学習していない |
| 式8–10、Algorithm 2 | advantages / gradient_probe | 合成した候補群で初期勾配だけを計算する。GRPOの全過程は再現しない |
| 表1–3 | beam比較表、商品展開の操作 | 説明用に作ったスコアを使い、論文のヒット率は再現しない |
| 表4 | EvidenceのK=0/2比較 | 学習が崩れたというのは著者の解釈。Labの小実験では、その現象を検証していない |
| §4.5 | チャネル比率の積み上げ棒 | 50.25/58.96/72.63%は露出・クリック・購入それぞれの構成比であり、A/BテストのGMV・UCTCVRの改善率とは異なる |
