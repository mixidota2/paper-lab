# 論文とLabで確認した処理の対応

この表は[論文第2版](https://arxiv.org/html/2605.14434v2)のどの箇所をLabのどの説明や人工例で扱うかを示します。著者の実装へのリンクは論文で確認できなかったため、著者のコードと照合した表ではありません。

| 論文の箇所 | Labで読めるもの | Labが確認した範囲 |
|---|---|---|
| §3.1、式1〜7 | `method.md` と量子化の図 | カテゴリ番号を使う段と残差を近似する段を説明します。RQ-VAEやEMA、InfoNCEは実装していません。 |
| Algorithm 1 | `run.py` の `split_cluster` | 分けた後の群の件数だけを計算します。件数がほぼ等しくなるように分けますが、商品一つずつを無作為に割り当てる処理は行いません。 |
| §3.2 | `method.md` の学習手順 | 入力に何を足していくかを説明します。Qwen2.5-0.5Bは学習していません。 |
| 式8〜10、Algorithm 2 | `advantages` と `gradient_probe` | 人工のSIDから平均報酬との差と、更新前の方策での初期勾配を計算します。GRPOを繰り返して収束させる処理は行いません。 |
| 表1〜3 | 評価の比較表と商品展開を試す操作 | 同じSID数での比較と同じ商品上限での比較を区別します。操作では人工の点を使い、論文のヒット率は再現しません。 |
| 表4 | 標準GRPOと教師例を加えた場合の比較 | 著者は標準GRPOで上位の候補に偏ったと解釈しました。Labはその現象を検証していません。 |
| §4.5 | 本番導入後の帰属を示す図 | 全体の露出50.25%、クリック58.96%、購入72.63%が生成経路にも帰属しました。著者は複数経路への重複帰属を認めています。これらはA/BテストのGMV・UCTCVRの増加率ではありません。 |
