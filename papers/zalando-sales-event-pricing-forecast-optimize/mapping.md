# 原論文とLabの対応

一次資料は[原論文のv1](https://arxiv.org/pdf/2606.13741v1)です。以前の照合では、提供されたPDFの全14ページを読み、SHA-256をlab.yamlに記録しました。本文から公式実装のURLは確認できず、Labは公式コードを実行していません。

| 原論文 | Labで確認できること | Labに含めていないこと |
| --- | --- | --- |
| Fig. 3、§3.1、Table 1 | LabはLightGBMで割引率ごとの需要を予測します。割引率を上げても予測需要が下がらないように制約します。 | 市場と予測日ごとに学習する代わりに、共通の小さなモデルを使います。 |
| 式(1)、Fig. 4 | run.pyのmainでは、純売上に掛ける重みαを21通りに変え、そのたびに長期利益との合計が最も大きくなる割引を選びます。 | 架空の3商品だけを使います。離散候補のPareto解はすべて列挙しません。 |
| 式(3)〜(7) | financial()は、返品率R、付加価値税VAT、費用C、残る在庫1単位から見込める利益γを固定して計算します。 | 週次モデルを使ってγを求める処理はありません。 |
| 式(12)、§4.1 | experiment()は、価格弾力性を一定とした需要に対数正規ノイズを加えます。モデルは56日分のデータで学習します。 | 論文で100週にわたり在庫を売り切るために使ったルールは含めません。 |
| §4.2、Table 3 | Labは同じ特徴量でMSEとTweedieのモデルを学習し、それぞれが選んだ割引の結果を比べます。 | 学習データの価格は無作為に割り付け、既知の弾力性を入力します。モデルが選んだ価格は期待需要で評価します。 |
| Table 2、p.9 | results.jsonのpaper_evidence.table2に、主要3モデルについて著者が報告した平均値を載せています。 | 図に標準偏差は表示しません。 |
| Table 3、p.10 | paper_evidence.table3に、真の需要を知る比較条件（oracle）に対する利益貢献（PCII）の比を載せています。 | 著者のシミュレーションの値で、現場のA/Bテストの値ではありません。 |
| Table 4–5、pp.11 | paper_evidence.table5と統合効果の図に、著者が23試験をまとめた結果を載せています。 | 試験を実施した回ごとの効果と区間は復元していません。 |

results.jsonには、著者が報告した数値とLabの最小実験の結果を別々に保存します。paper_lab/zalando05.pyは、その値をHTMLに表示します。HTMLを数値の原本にはしません。損失関数を変えるだけで、現場でも同じ因果効果が得られるとは言えません。
