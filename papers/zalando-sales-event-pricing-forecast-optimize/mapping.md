# 原論文とLabの対応

一次資料は [High-frequency pricing at scale for e-commerce v1](https://arxiv.org/pdf/2606.13741v1)。提供PDFの全14ページを読み、SHA-256をlab.yamlに記録しました。本文から公式実装のURLは確認できず、公式コードは実行していません。

| 原論文 | Labで確認できること | Labに含めていないこと |
| --- | --- | --- |
| Fig. 3、§3.1、Table 1 | LightGBMで割引率ごとの需要を予測します。割引率と予測値の関係には単調制約を置きます。 | 市場別・予測日別のモデルを、共通の小さなモデルで置き換えます。 |
| 式(1)、Fig. 4 | run.pyのmainで、長期利益に足す純売上の重みαを21通りに変え、割引を選びます。 | 架空の3商品だけを扱い、離散的な選択肢からPareto解をすべて列挙することはしません。 |
| 式(3)〜(7) | financial()は、返品率R、付加価値税VAT、費用C、残る在庫1単位の将来利益γを固定して利益を計算します。 | γを週次モデルから推定する処理はありません。 |
| 式(12)、§4.1 | experiment()は、価格弾力性を一定とした需要に対数正規ノイズを加え、56日分でモデルを学習します。 | 100週にわたって在庫を売り切るための原論文のルールは使いません。 |
| §4.2、Table 3 | 同じ特徴量で学習したMSEとTweedieのモデルをそれぞれ割引選びに使い、選択の結果を比べます。 | 学習データでは価格をランダムに割り付け、既知の弾力性を入力します。選んだ価格の評価には期待需要を使います。 |
| Table 2、p.9 | results.jsonのpaper_evidence.table2に主要3モデルの平均値を載せています。 | 図では標準偏差を表示していません。 |
| Table 3、p.10 | paper_evidence.table3に、著者が利益貢献（PCII）を、真の需要を知る条件（oracle）に対する比で示した値を載せています。 | 著者のシミュレーション結果です。現場のA/Bテストの値ではありません。 |
| Table 4–5、pp.11 | paper_evidence.table5と統合効果図に23試験をまとめた結果を載せています。 | 実施回ごとの効果や、その区間推定は復元していません。 |

results.jsonでは、著者報告の数値とLabの最小実験の結果を別のキーに保存します。paper_lab/zalando05.pyはそれらを表示し、HTMLを数値の原本にはしません。損失関数を変えるだけで現場でも同じ因果効果が得られるとは主張しません。
