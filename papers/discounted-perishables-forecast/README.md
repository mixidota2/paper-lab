# 期限間近の食品の値引き販売を、通常需要にどこまで含めるか

値引き品が2個売れても、その商品が合計で2個多く売れたとは限りません。値引きしなくても買った人が、値引き品を選んだだけかもしれないからです。この教材では、販売記録が同じでも、値引きで増えた販売数が異なる二つの例を比べます。どちらも回帰の傾きは1ですが、一方では値引きで増えた数が0個です。通常価格で売れるはずの商品が値引き品に置き換わる例も試せます。

リポジトリのルートで `uv run --locked python papers/discounted-perishables-forecast/run.py` を実行すると、三つの例の結果が表示されます。末尾に `--write` を付けると、スクリプトは同じディレクトリにある `results.json` を作り直します。スクリプトはPython標準ライブラリの有理数で計算します。ブラウザでは `interactive.html` を開いてください。画面は同じフォルダの `model.js` と `interactive.js` を使い、外部に通信しません。

結果の `slope` は回帰で求めた傾きです。曜日、小売が使った予測値、朝の在庫数をそろえて比べると、値引き品が1個多く売れた行で、実績と予測の差が平均で何個違うかを表します。`true_increment` は、人工例で値引きした場合としなかった場合の総販売数の差です。スクリプトは値引き品が売れた行について、その差の平均を求めます。

[原論文](https://arxiv.org/html/2602.04464v1)は食品小売店の販売記録を分析しました。Labは論文の二段階の回帰を人工データで動かし、同じ傾きから異なる結論が生まれる例を示します。論文と同じデータで数値を再計算したり、実店舗で値引きの効果を確かめたりしたわけではありません。
