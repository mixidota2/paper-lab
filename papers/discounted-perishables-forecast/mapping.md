# 論文の手順をLabのどこで確かめられるか

| 論文の手順 | Labが人工例で行ったこと | Labが確認していないこと |
|---|---|---|
| §2：商品・店舗・営業日ごとの記録を集める | 同じ項目を持つ人工データを作り、値引き品が売れた行と、売れなかった行を分けました。 | 元データを入手しておらず、欠測の処理も再現していません。 |
| 式1：曜日、小売の予測、朝の在庫で総販売数の基準を作る | 値引き品が売れなかった行だけで回帰し、基準の販売数を推定しました。 | 小売が使っていた元の予測モデルは再学習していません。 |
| 式2・3：基準からの差と値引き販売数の関係を調べる | 値引き販売数にかかる係数を計算し、目的変数を総販売数や通常価格での販売数に変えたときと比べました。 | 論文の係数や個別のt検定は再計算していません。 |
| §5：値引きシールを貼った数も記録するよう提案する | 店がシールを貼っても、その商品が売れなかった行を人工例に入れました。 | 店舗の廃棄、利益、在庫がどれだけ変わるかは測っていません。 |
