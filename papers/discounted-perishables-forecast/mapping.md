# 論文とLabの対応

| 論文上の処理 | Labで確認できること | Labで確認していないこと |
|---|---|---|
| §2：SKU×店舗×営業日の観測 | 同じ列構成の人工データで値引き販売ゼロ・正を分ける | 元データと欠測処理の再現 |
| 式1：曜日、事業者の予測、朝の在庫で総数を回帰 | 値引き品の販売ゼロの行で基準を推定する | 小売の予測器の再学習 |
| 式2・3：正の値引き販売がある行で残差を回帰 | 値引き販売の傾きを再計算し、総販売数と通常価格販売数での傾きも比べる | 原論文の推定値やt検定の再現 |
| §5：値引きシールの付いた数を別に記録するという提案 | 値引きしたことと値引きで売れたことが異なる行を含める | 廃棄・利益・在庫への効果の測定 |
