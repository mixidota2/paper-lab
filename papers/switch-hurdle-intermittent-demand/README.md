# Switch-Hurdle：売れる日と、売れたときの個数を分けて予測する

MușatとCăbuzは、ゼロが続くことがある商品の販売数を、二つに分けて予測した。一つは1個以上売れる確率、もう一つは売れた日の数量の分布である。著者は過去56日から次の28日を予測し、M5の30,490系列と社内データの約40,000系列で他のモデルと比べた。[原論文 v1](https://arxiv.org/pdf/2602.22685v1)

M5では、複数の集計単位の予測誤差を重み付きでまとめたWRMSSEが0.6307だった。比較にあるTSMixerの0.6403やTFTの0.6932より小さい。ただし、ほかの指標ではSwitch-Hurdleの誤差が最小とは限らない。著者は在庫費用や欠品が改善したかを測っていない。

## 著者のモデルが計算する順序

著者のモデルは、過去の各日の入力を1つの処理ネットワーク（expert）に渡す。モデルはその送り先を学習する。デコーダーは前日の予測と、その日に分かっている情報を使い、売上がゼロでない確率と、売れた日の個数の分布を別々に出す。個数の分布は、負の二項分布から0個を除いて作る。

たとえば、売れる日の平均が同じでも、売れる日が2倍になれば、全日で平均した販売数は変わる。モデルが二つを分ける理由は、売れる頻度が変わったのか、売れた日に多く売れたのかを区別するためである。

## 教材で確率を計算する

リポジトリの最上位で `uv run papers/switch-hurdle-intermittent-demand/run.py` を実行すると、同じフォルダーの `results.json` が更新される。Pythonの標準ライブラリだけを使う。

教材は、負の二項分布の元の平均μとばらつきのパラメータαを固定し、売れる確率p⁺を0.1、0.5、0.9に変える。別の条件ではp⁺を0.5のまま、μを6に変える。計算は0〜999個の確率を足して分布の合計と平均を確かめ、図は0〜20個とその外に残る確率を示す。

μ=2、α=0.5では、元の負の二項分布が0個をとる確率は0.25である。0個を除いた分布の平均は約2.6667個になる。p⁺=0.5なら、売れない日も含めた平均は約1.3333個である。同じμとαでp⁺だけを変えても、売れた日の平均は変わらない。

Labが確認したのは、この確率計算と保存値の再生成である。著者のエンコーダーやデコーダーを学習させたり、M5の成績、規模を広げた際の性能や実店舗での欠品・費用を測ったりはしていない。
