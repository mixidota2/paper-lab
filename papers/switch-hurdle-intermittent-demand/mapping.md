# 論文の図と式を、Labのどこで確かめられるか

Labは2026年9月29日に、保存済みの[原論文 v1](https://arxiv.org/pdf/2602.22685v1)とarXivの版情報を照合しました。

PDF SHA-256: `0ea7569ce0136f13c710a18caeee577e4b308c62df7ad7102bfa7e2ceb52dff7`

| 論文の箇所 | Labに載せたもの | Labが試していないこと |
| --- | --- | --- |
| 図1・式2〜3：エンコーダーの振り分け | 順伝播で一つを選び、振り分け器の学習に選択前の確率を使う仕組みを図にしました。 | 同じエンコーダーを訓練していません。 |
| 式8〜14：発生確率と数量分布 | `nb()` と `hurdle()` で、0個と1個以上の確率を算出しました。 | デコーダーや学習の損失関数は実装していません。 |
| 図4〜5：需要区分ごとの振り分け | 学習後のモデルが、どの区分の入力をどのネットワークに送ったかを表にしました。 | Labでモデルを訓練して同じ振り分けが起きるかは試していません。 |
| 表4：M5の予測精度 | 著者が報告した予測誤差を棒グラフにしました。 | M5でモデルを訓練し直して、精度を測ったわけではありません。 |

[Accuracy Is Not Service](https://mixidota2.github.io/paper-lab/papers/accuracy-not-service-intermittent-demand.html)では、予測誤差の大きさだけでは、欠品や在庫の費用が改善したか判断できない理由を説明しています。

確認したPDFとarXivの概要ページでは、著者のコードを公開したリポジトリへの案内は見つかりませんでした。公開コードが存在しないとは断定できません。`run.py` はLabが確率の計算を説明するために作ったものです。
