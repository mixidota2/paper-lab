# 原論文の規則と教材の違い

[原論文](https://arxiv.org/html/2610.32285v1)の§2〜4、§5.1〜5.2を確認しました。§5.3の表本文はHTMLで表示されなかったため未確認です。著者のコードや実験時の原記録は取得していません。

| 原論文で確認した規則 | この教材で試せる範囲 |
| --- | --- |
| §3.1・§3.4：採点する前に、実行結果と保存記録が対応しているか確かめる | チェック欄で整合性の有無を仮定する。記録そのものは検査しない |
| 表4：基盤の判定には4状態あり、状態2は成果が全項目合格かどうかで決まる | 基盤の1項目だけを切り替え、もう1項目は合格に固定する |
| 式3：成果と基盤の合格割合を、それぞれ50点満点に換算する | 計算関数は別々の分母を扱える。画面では各層2項目に固定する |
| 式4：観測の迂回があった項目は、採点上の不合格に残すが、基盤側の失敗を絞り込むときに除く | 画面では唯一切り替えられる基盤項目だけに迂回を設定できる |
| 式6：事前に定めた基盤・成果の項目がともに不合格で、条件にも合うと候補になる | 迂回を除く前の不合格で候補を判定する。候補は因果関係の確定を意味しない |
| §3.5：途中の情報変化などを調べ、実際に失敗が伝わったかを確かめる | 伝播の検証は行わない |

画面、図、数値例はこのLabで作成しました。著者の図は転載していません。論文の集計やモデルの順位は実装対象外です。
