# 論文の評価と教材の対応

著者は実行記録や成果物を照合します。Labでは、照合した結果を入力として与え、そこから得点や失敗の候補がどう決まるかだけを計算します。

| 論文の箇所 | 著者が確認すること | Labで試すこと |
|---|---|---|
| §3.1と§3.4 | 採点に入る前に、実行と保存記録が対応するかを確かめる。 | チェック欄で対応していると仮定する。記録は読まない。 |
| 表4 | 状態2は、仕組みを使う処理を通らず、成果の全項目が合格した場合だけ基盤項目を1にする。 | 基盤の1項目を状態2のままにして、成果の合否を変える。 |
| 式3 | 成果と基盤の合格割合を50点ずつに換算する。 | 画面は各層2項目。計算関数は層ごとに異なる分母も扱える。 |
| 式4 | 観測の迂回があった項目は得点の計算に残し、基盤側の原因を調べるときに除く。 | 一つだけ変更できる基盤項目に迂回を設定する。 |
| 式6 | 基盤と成果に事前に定めた0があり、条件にも合えば候補を記録する。 | 迂回を除く前の0から1組の候補だけを見る。人が記録を読んで実際の原因を調べる工程は含まない。 |

論文の[§5.1と表6](https://arxiv.org/html/2610.32285v1#S5)では、成果の全項目に合格した実行が1,351件、基盤の全項目にも合格した実行が286件です。差の1,065件は採点を終えた3,420件の31.1%に当たります。元の実行や採点結果をLabで再計算した値ではありません。論文のモデル別表（§5.3）の本文は、確認したHTMLでは表示されませんでした。
