# Explainable Recommendations at Scale: LLM Rationales for YouTube Music Artist Discovery

YouTube Musicの研究チームは、ホーム画面の「Your Daily Discover」で、知らないアーティストを見つけやすくする方法を試しました。従来は、よく一緒に聴かれるか、音などの特徴が似ているかを基準に候補を探し、「好きなアーティストのファン向け」のような定型文で理由を示していました。新方式では、利用者の好みのまとまりごとに、大規模言語モデルが新しい候補と推薦理由を事前に作ります。理由文は、新しい候補だけでなく従来の候補にも付けられます。

2週間の本番実験で、著者はこの推薦欄での反応が22.43%増え（95%信頼区間は16.93〜27.93%）、発見や継続利用に関する指標が8.07%上がったと報告しています。候補と画面を変えずに理由文だけを外すと、候補の追加と理由文の両方を外したときと同程度に、利用者の反応が減りました。新しい候補を増やす機能だけを外した場合、反応に明確な差は出ていません。これらはこの推薦欄での結果で、YouTube Music全体の利用継続率ではありません。

## このLabの問い

まだ聴いていないアーティストを候補に加える効果と、候補に理由を添える効果は、どの比較で見分けられるか。
