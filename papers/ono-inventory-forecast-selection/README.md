# 商品ごとに予測手法を選ぶと、在庫費用は下がるか

Onoらは発注したあとの在庫費用を基準に、商品ごとに予測手法を選べるかを調べました。著者はWalmartの公開売上データを使い、州ごとの仮想倉庫で発注をシミュレーションしました。提案手法のCFMSは、商品と州の組み合わせごとに予測手法を選びます。比較対象の単純指数平滑法（SES）は、どの系列にも同じ方法で予測します。

主な比較で著者は、総費用をCFMSで85,056、SESで85,093と報告しました。SESを基準に約0.04%の差です。著者が手法ごとの平均順位を検定した結果、この2手法にはっきりした差はありませんでした。CFMSは発注費用と保管費用を抑えましたが、欠品費用は増えました。ここで比べているのはシミュレーションの費用で、実店舗が支払った金額ではありません。

```sh
python3 papers/ono-inventory-forecast-selection/run.py
```

このコマンドには追加ライブラリが要りません。スクリプトは表2と表7の報告値を使って費用差を計算し、結果を同じフォルダの `results.json` に書き出します。欠品の回数と数量の違いを示す架空の例も同じファイルに入ります。論文のモデルの学習や補充シミュレーションは実行しません。

著者がどの期間と条件で比べたかは [method.md](method.md)、Labの数値が論文のどこに対応するかは [mapping.md](mapping.md) に記載しています。
