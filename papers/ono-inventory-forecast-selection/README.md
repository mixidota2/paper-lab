# 商品ごとに予測手法を選ぶと、在庫費用は下がるか

Onoらは、予測誤差ではなく、その予測で発注したあとの費用を基準に予測手法を選びました。著者らはWalmartのM5公開売上データに仮想の倉庫を設けて、発注後にかかる費用をシミュレーションしました。提案手法のCFMSは、売れ方と補充条件を手がかりに、各候補の在庫費用の相対成績をLightGBMで見積もります。その結果を使い、商品と州の組み合わせごとに予測手法を選びます。比較対象の単純指数平滑法（SES）は、全系列を一つの手法で予測します。

主な比較の総費用は、CFMSで85,056、SESで85,093でした。SESを基準にした差は約0.04%です。CFMSでは発注と保管の費用が減りましたが、欠品の費用は増えました。著者らが手法の平均順位を検定したところ、両手法にはっきりした差はありませんでした。この数字は著者らが設定した条件でのシミュレーション結果で、実店舗が支払った金額ではありません。

### Labで確かめること

```sh
python3 papers/ono-inventory-forecast-selection/run.py
```

スクリプトは追加ライブラリなしで動きます。表2と表7の報告値から費用差を計算し、同じフォルダの `results.json` に書き出します。合計の欠品が同じ4個でも、欠品が起きるサイクルの数を変えると指標はどう変わるか。架空の例でも確かめます。モデルの学習や補充シミュレーションは実行しません。

著者らが比較した期間と条件は [method.md](method.md)、Labで読み直した論文の数値は [mapping.md](mapping.md) にまとめています。
