# 商品ごとに予測手法を選ぶと、在庫費用は下がるか

OnoらがM5の売上データで行った補充シミュレーションを読み解きます。論文は商品に合わせて予測手法を選ぶCFMSと、全商品で単純指数平滑法（SES）を使う方法を比較しています。主な比較では、費用に統計的にはっきりした差がありませんでした。

```sh
python3 papers/ono-inventory-forecast-selection/run.py
```

追加ライブラリは不要です。実行すると同じフォルダの `results.json` に、表2と表7の比較、およびサービス指標を説明する人工例が入ります。論文のモデルは学習し直しません。評価条件は [method.md](method.md)、原論文との対応は [mapping.md](mapping.md) に記載しています。
