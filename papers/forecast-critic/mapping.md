# 論文の実験と、Labが計算した範囲を区別する

Labは[arXiv:2512.12059v1](https://arxiv.org/html/2512.12059v1)の公開HTMLで、人工データの作り方、M5のデータと結果、加重F1の定義を確認しました。原典バイト列のハッシュは未取得です。

| 論文の実験 | 著者が行ったこと | Labの教材が確認していないこと |
| --- | --- | --- |
| 人工的に予測線を変える | 変え方ごとに334候補を作り、SMAPEが悪化した候補から上位75%の250件を選びました。手を加えていない250件と比べています。付録Aの加重F1は、クラスごとのF1を件数で重み付けします。 | Labは画像を読み取るLLMを実行していません。論文のF1や、実店舗で自然に起きる誤りの率は再現していません。 |
| 販促予定を文章で渡す | 図5と付録Dの図12では、著者は過去の販促で売上が増えたかによって正解を変えました。過去に増えた場合は山のある予測を妥当とし、逆の場合（履歴で売上増なしなら山なしを妥当・山ありを不適切）は判定を逆にしました。 | Labは販促の文章を入力しておらず、実店舗における販促の因果効果も測っていません。 |
| M5の実績で警告の意味を確かめる | 著者は1,000系列から、履歴120日と、Chronosの中央値および10・90分位で表した予測28日を見せました。共変量は加えず、警告が多かったため指示文を調整しました（付録E）。実績が得られたあと、警告あり・なしの群のsCRPSを比べました。 | LabはChronosやM5を実行していません。警告を受けて予測を直した場合の誤差や費用の改善も測っていません。 |

Labの人工例は10件です。うち6件を不適切と決めて、警告を出す基準を0〜10に変えたときの誤警告と見逃しを数えます。記事に載せた表は閾値5の保存結果です。ページに閾値を変更する操作はありません。警告を1件も出さなかったときは、適合率の分母が0になるため未定義です。JSONではnullで表します。

リポジトリのルートで `uv run papers/forecast-critic/run.py` を実行すると、Python標準ライブラリと共有の `papers/_toy_common.py` が結果を計算し、`results.json` を更新します。
