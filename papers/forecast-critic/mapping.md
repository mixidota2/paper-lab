# 論文で確認したことと、Labで計算したこと

[arXiv:2512.12059v1](https://arxiv.org/html/2512.12059v1)の公開HTMLで、Dataset construction、M5 Dataset construction / Empirical results、Appendix Aを確認しました。原典バイト列のハッシュは未取得です。

- **人工的な変更**：変更の種類ごとに334候補を作り、SMAPEの悪化が大きい上位75%から250件を選んで、未変更の250件と比べます。自然発生する失敗の無作為標本ではありません。
- **F1の集計**：Appendix Aのweighted F1はクラス別F1の件数加重平均で、不適切な予測だけを対象としたF1とは異なります。
- **M5の評価**：1000系列を対象に、履歴120日と、Chronosの中央値・10/90分位で表した予測28日の画像を渡します。補助情報（共変量）は渡しません。過剰な警告を受けて指示文を調整しています（Appendix E）。警告あり・なしのsCRPS差は、導入後の予測改善幅ではありません。
- **販促の合成4条件**：今回の販促予定に加え、過去の販促時に売上が増えたかを使って正解を決めます。履歴で売上増ありなら山ありを妥当・山なしを不適切、履歴で売上増なしなら山なしを妥当・山ありを不適切とします（Exogenous Feature Injection、Figure 5、Appendix D Figure 12）。実店舗における販促の因果効果は検証していません。

Labは手作りの10件（陽性6/10）で、警告の基準を変えると誤警告と見逃しがどう変わるかを計算します。ページに載せた表は閾値5の保存結果で、閾値を動かすUIはありません。コードは0〜10を計算し、警告が0件のときの適合率は未定義（JSONではnull）とします。著者のF1や言語モデルによる画像理解は再現していません。

リポジトリルートで `uv run papers/forecast-critic/run.py` を実行すると、標準ライブラリと共有の `papers/_toy_common.py` で計算し、結果JSONを更新します。
