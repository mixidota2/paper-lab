# 予測を作るモデルと、点検に回すモデルを分ける

Forecast Criticは、実績と予測を描いたグラフを読み、担当者が確かめるべき予測に印を付けます。判定には画像と文章を読める大規模言語モデル（マルチモーダルLLM）を使います。販促予定などは文章で添えます。判定時には未来の実績を見せません。予測値を出したり、予測線を直したりする仕組みでもありません。

## 人工的に崩した予測を、未変更の予測と比べる

著者は、傾き、上下の位置、山と谷の間隔、局所的な突出を変えました。変更の種類ごとに334候補を作り、SMAPE（実績と予測の大きさを基準にした誤差率）の悪化が大きい上位75%から250件を選んでいます。未変更の250件と比べるための集計で、現場で自然に起きた誤りの無作為標本ではありません。

比較した判定モデルはClaude 3.7 Sonnet、Claude 4.0 Sonnet、同reasoning版、Claude 4.0 Opus、Llama 4 Maverickです。Appendix Aのweighted F1は、クラス別のF1を各クラスの件数で重み付けして平均した値です。不適切な予測だけを陽性としたF1とは区別します。

## M5では、後から実績を使って警告の意味を確かめる

無作為に抽出した1000系列について、履歴120日と予測28日を図にします。見せるのはChronosの中央値と10・90分位で、予測対象以外の補助入力（共変量）や販促の文章は加えません。警告が出すぎたため、著者は「明らかな誤りだけ」を指摘するようにモデルへの指示文（prompt）を調整しました（M5 Dataset construction / Empirical results、Appendix E）。警告あり・なしの群のsCRPS差は、警告後に予測を直して得た改善ではありません。

## 販促予定が同じでも、過去の売上によって妥当な線は変わる

原論文の販促実験では、今回の予定だけでなく、過去の販促日に売上が増えたかも条件にします。過去に増加があり今回も販促するなら、山のある予測を妥当、山のない予測を不適切とします。過去に増加がなければ、次に販促する場合でも山がない方を妥当とします（Exogenous Feature Injection、Figure 5、Appendix D Figure 12）。これは人工例の正解の決め方であり、販促が実店舗で売上を増やすことの証明ではありません。

「形が不自然」と「結果として誤差が大きい」は別です。現場で試すなら、正しい予測を誤って止める件数と、人が確認できる警告の件数も測ります。
