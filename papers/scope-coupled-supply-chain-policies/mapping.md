# 原論文とLabの実装の対応

一次資料は[原論文v1](https://arxiv.org/pdf/2607.28488v1)です。図1・2、§3.1〜3.3、式(1)〜(6)、表1・2を確認しました。保存したPDFのSHA-256は `0e0ea2b7b37d2a34c9aa11be36332ac0df193508e4e6044475e9d26ea060c5a9` です。

| 原論文 | Labで読む場所 | Labで再現していないこと |
| --- | --- | --- |
| 式(1)・(2) | `utility()` と操作図で、補充間隔を変えると荷量と配車費がどう変わるかを計算します。 | 実際の道路距離、車両の重量・容積の両方の上限、在庫の推移。 |
| 式(3)・(4) | `experiment()` で、固定した品揃えのもとで補充間隔を選ぶ場合と、両方を全候補から選ぶ場合を比べます。 | 複数の供給元、複数拠点の配送経路、原論文の規模での最適解。 |
| 図1・2、§3.2〜3.3 | 手法の説明と図で、前の判断を次へ渡す方法、段階ごとの学習、検証での候補選択を説明します。 | ニューラルモデルの学習、OR-Toolsの教師データ、近似経路の計算。 |
| 表1・2、§4.5 | 本文で、日次の代理評価値と需要のカバーの割合を分け、著者報告と人工例を区別します。 | Dingdong・JD.comの再計算、会社の実現利益、実店舗や倉庫での運用。 |

確認したPDFでは公式実装へのリンクを見つけられませんでした。公開実装が存在しないという意味ではありません。Labは著者のコードを実行せず、式と報告値をもとに、読者向けの図と人工例を用意しました。

`lab.yaml` が記事と図、`method.md` が手法、`run.py` と `results.json` が人工例の計算と結果を持ちます。HTMLでは論文の報告値と人工例を別の図にしています。
