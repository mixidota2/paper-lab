# 補正の配分を学習する方法

## 学習データと、欠品で見えない需要

著者が共通形式に変換したデータ全体は約1,130万系列、484億観測点です（表3）。学習用に残ったのは10,049,114系列で、評価用と重複除外分は含みません（表4）。人工データは8種類の型から作った47,500系列です。生成器はベルヌーイ分布によるマスクや負の二項分布を使って需要を生成し、潜在需要、在庫の範囲で売れた数量、欠品フラグを別々に記録します。人工データでは潜在需要を先に作るので両者を比べられますが、それだけで実際の販売記録から欠品中の需要を復元できるわけではありません。

## 需要型の教師比率

ADIは観測期間数をゼロでない期間数で割った値で、需要が発生する間隔を表します。CV²はゼロでない数量の分散を平均の2乗で割った値です。式5・6はこれらを対数に変換し、境界の近くで分類が急に切り替わらないようにします。

`a = sigmoid(log(ADI / 1.32) / 0.35)`

`c = sigmoid(log(CV² / 0.49) / 0.60)`

`π = [(1−a)(1−c), a(1−c), (1−a)c, ac]`

πの成分は順にSmooth、Intermittent、Erratic、Lumpyです。間隔が短く数量のばらつきも小さければSmooth、間隔が長いだけならIntermittent、ばらつきが大きいだけならErratic、両方ならLumpyの比率が大きくなります。式10は各成分を1/T乗し、合計が1になるように割り直します。論文ではT=0.5なので、`π̃ = π² / Σπ²` となり、もともと比率の高い成分を相対的に強めます。4成分がすべて同じ点では、変換後も同じです。

## 学習済みの配分器が出す比率

予測時に使うのはπやπ̃ではなく、学習済みの配分器（router）が出すqです。元の入力系列から、ゼロとみなした値の比率、ADI、非ゼロCV²、時間との相関、1次自己相関、増加した組の割合、ゼロを含むCV、系列長の8つを求めます。式4はADI・非ゼロCV²・全期間CV・系列長を対数で圧縮し、増加割合uを2u−1に変えます。

補正を加える線形変換（投影）ごとに、小さな2層ネットワークを置きます。各配分器は同じ8つの値を読みますが、自分の投影で使うqを計算します。同じ投影内では、その系列の全トークンに同じ配分を使います。学習時には予測誤差と、qを学習用の教師比率π̃に近づける補助損失を足します。予測時には補助損失も分類式も使いません。操作図はπとπ̃までを計算し、qは表示しません。

## 固定した変換に足す5本の補正

式11は `y = W₀x + Σₑ gₑ (α/rₑ) BₑAₑx` です。LoRAでは、基盤モデルの重みW₀を固定し、2つの小さな行列の積で補正します。共有の補正はランク16で、どの系列にも重み0.5で使います。4本の需要型別の補正はそれぞれランク4で、残りの0.5をqの比率で分けます。各補正にはα/rₑ（α=8）も掛けます。1本だけを選ぶ振り分けではありません。

著者は各層で注意機構の4つとフィードフォワードの2つの投影に補正を加え、24層で計144か所を変更しました。学習の勾配は補正行列と配分器に伝え、基盤モデルの重みは更新しません。共有の補正は配分器の補助損失の対象ではありませんが、予測損失で学習します。実装では、式12のように補正行列をランク方向に積んで、行列積をまとめます。
