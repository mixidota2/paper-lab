**著者の方法。** 学習用データは、合成した47,500系列を含め、全体で約1,130万系列・484億観測点になる。基盤モデル（backbone）の重みは変えず、全系列に共通する補正（LoRA）を1本、需要クラス別の補正を4本追加する。どの補正をどれだけ使うかは系列ごとに決める。LoRAは大きな重み行列を、小さな行列の積で補正する方法である。

**本Labの解釈。** 業種名で専門家を分けるより、需要が途切れる頻度と数量変動で分けるという設計が読みどころになる。境界に近い系列を1種類に決めつけず、複数の種類に近いものとして学ぶ。予測時には分類式を使わない。配分を決める小さなモデル（router）が、予測時点までの系列から得た8統計量を受け取り、比率を出す。

ADI = 観測期間数 / 非ゼロ期間数、CV² = 非ゼロ数量の分散 / 平均²とする。式5–6は対数軸上で境界を柔らかくする。

`a = sigmoid(log(ADI / 1.32) / 0.35)`

`c = sigmoid(log(CV² / 0.49) / 0.60)`

`π = [(1−a)(1−c), a(1−c), (1−a)c, ac]`

πの成分は、順にSmooth、Intermittent、Erratic、Lumpy。式10の教師分布は`π̃ = π² / Σπ²`で、温度T=0.5により優勢な成分を強める。routerはゼロ比率、ADI、CV²、時間との相関、1次自己相関、増加割合、全期間のCV、系列長を読む。式4では、ADI、非ゼロCV²、全期間CV、系列長の4つを対数で圧縮する。増加割合には2u−1を使う。π̃は分類統計から作る学習用の教師比率、qは学習済みのrouterが出す配分比率だ。画面で計算するのはπ̃までで、学習済みのqは出さない。各投影に配分器がある。どの配分器も同じ8統計量を読むが、配分は投影ごとに計算する。同じ投影では、系列内のすべてのトークンに同じ配分を使う。

式11は`y = W₀x + Σₑ gₑ (α/rₑ) BₑAₑx`。元の重みW₀は固定する。共通する補正に0.5を割り当て、残り0.5を4つの補正にqの比率で分ける。共有rank=16、各専門枝rank=4、α=8。24層×6投影=144か所へ付ける。式12はrank方向に枝を積み、行列積をまとめる実装である。
