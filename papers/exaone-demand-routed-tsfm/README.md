# EXAONE Demand 1.0：需要の出方に応じて予測を補正する

## 概要

LG AI Researchは、毎日のように売れる商品と、需要がない日が続く商品とで、時系列モデルの予測をどう変えるかを調べました。EXAONE Demandは土台となるモデルを固定し、需要が起きる間隔や、起きたときの数量のばらつきなどを見て、複数の補正をどの割合で使うかを決めます。

著者が22のデータセットで比べたところ、予測誤差の尺度をそろえる指標MASEは、実データと人工データで学習した版が1.0667、人工データだけで学習した版が1.0742でした。どちらも補正しない土台のモデルの1.1050や、比較対象のTiRex-1.1の1.0818より小さい値です。ここで比べたのは予測誤差で、在庫費用や欠品への効果ではありません。

## 問題設定

売れる間隔が長い商品でも、売れるたびに数量がほぼ同じ場合と、大きく変わる場合では、予測に使いたい手掛かりが違います。また、販売数がゼロでも、注文がなかったとは限りません。欠品の日には、買いたい人がいても販売数に表れません。

著者は93のデータ源を集め、73を共通形式に変換しました。変換したデータ全体では、エネルギーが系列数の39.87%、観測点数の67.51%を占めます。小売は系列数の17.18%、観測点数の1.33%です（表11）。需要向けと呼ぶモデルでも、小売データが学習データの大半を占めるわけではありません。

## 分類と配分の違い

著者は需要データで基盤モデルの補正を学習し、需要の発生間隔と数量のばらつきから作った比率を配分器の学習に使いました。

Labは、分類式から学習用の比率を計算する手順と、学習済みの配分器が予測時の比率を決める手順を区別します。予測誤差の差だけでは、在庫や欠品への効果は分かりません。

## 補正の配分を学習する方法

### 学習データと、欠品で見えない需要

著者が共通形式に変換したデータ全体は約1,130万系列、484億観測点です（表3）。学習用に残ったのは10,049,114系列で、評価用と重複除外分は含みません（表4）。人工データは8種類の型から作った47,500系列です。生成器はベルヌーイ分布によるマスクや負の二項分布を使って需要を生成し、潜在需要、在庫の範囲で売れた数量、欠品フラグを別々に記録します。人工データでは潜在需要を先に作るので両者を比べられますが、それだけで実際の販売記録から欠品中の需要を復元できるわけではありません。

### 需要型の教師比率

ADIは観測期間数をゼロでない期間数で割った値で、需要が発生する間隔を表します。CV²はゼロでない数量の分散を平均の2乗で割った値です。式5・6はこれらを対数に変換し、境界の近くで分類が急に切り替わらないようにします。

`a = sigmoid(log(ADI / 1.32) / 0.35)`

`c = sigmoid(log(CV² / 0.49) / 0.60)`

`π = [(1−a)(1−c), a(1−c), (1−a)c, ac]`

πの成分は順にSmooth、Intermittent、Erratic、Lumpyです。間隔が短く数量のばらつきも小さければSmooth、間隔が長いだけならIntermittent、ばらつきが大きいだけならErratic、両方ならLumpyの比率が大きくなります。式10は各成分を1/T乗し、合計が1になるように割り直します。論文ではT=0.5なので、`π̃ = π² / Σπ²` となり、もともと比率の高い成分を相対的に強めます。4成分がすべて同じ点では、変換後も同じです。

### 学習済みの配分器が出す比率

予測時に使うのはπやπ̃ではなく、学習済みの配分器（router）が出すqです。元の入力系列から、ゼロとみなした値の比率、ADI、非ゼロCV²、時間との相関、1次自己相関、増加した組の割合、ゼロを含むCV、系列長の8つを求めます。式4はADI・非ゼロCV²・全期間CV・系列長を対数で圧縮し、増加割合uを2u−1に変えます。

補正を加える線形変換（投影）ごとに、小さな2層ネットワークを置きます。各配分器は同じ8つの値を読みますが、自分の投影で使うqを計算します。同じ投影内では、その系列の全トークンに同じ配分を使います。学習時には予測誤差と、qを学習用の教師比率π̃に近づける補助損失を足します。予測時には補助損失も分類式も使いません。操作図はπとπ̃までを計算し、qは表示しません。

### 固定した変換に足す5本の補正

式11は `y = W₀x + Σₑ gₑ (α/rₑ) BₑAₑx` です。LoRAでは、基盤モデルの重みW₀を固定し、2つの小さな行列の積で補正します。共有の補正はランク16で、どの系列にも重み0.5で使います。4本の需要型別の補正はそれぞれランク4で、残りの0.5をqの比率で分けます。各補正にはα/rₑ（α=8）も掛けます。1本だけを選ぶ振り分けではありません。

著者は各層で注意機構の4つとフィードフォワードの2つの投影に補正を加え、24層で計144か所を変更しました。学習の勾配は補正行列と配分器に伝え、基盤モデルの重みは更新しません。共有の補正は配分器の補助損失の対象ではありませんが、予測損失で学習します。実装では、式12のように補正行列をランク方向に積んで、行列積をまとめます。

## 需要型を学習に使う理由

共有の補正が多くの系列に共通するずれを受け持てば、残る4本の補正は需要の出方ごとの差を学習しやすくなると著者は考えています。配分器は、基盤モデルが正規化した途中の表現ではなく、入力の系列から直接求めた統計量を使います。著者はSyntetos–Boylan–Croston（2005）の需要分類を、予測時の振り分け規則ではなく学習の手掛かりにしました。この点は、モデルの容量を増やすことを主な目的とするMoirai-MoEと異なります。ただし、固定した基盤モデルからの改善にはデータと補正方式の両方の違いが含まれ、配分器だけの効果は分かりません。

## 論文の比較結果

[一次資料（原論文v1）の表8](https://arxiv.org/pdf/2609.30880v1)は、22データセットの予測誤差を集計しています。実データと人工データを併用した版のMASEは1.0667で、補正しない基盤モデルの1.1050より約3.47%、比較対象で最も低かったTiRex-1.1の1.0818より約1.40%低い値でした。WQLは分位点予測の誤差を測ります。一方、予測区間を評価するMSISでは併用版が10.70、人工データだけの版が10.63で、すべての指標で併用版が良かったわけではありません。

| モデル | MASEの幾何平均 | WQL |
| --- | ---: | ---: |
| EXAONE Demand（実データと人工データ） | 1.0667 | 0.1138 |
| EXAONE Demand（人工データのみ） | 1.0742 | 0.1147 |
| TiRex-1.1 | 1.0818 | 0.1161 |
| Chronos-2 | 1.0885 | 0.1406 |
| 補正しない基盤モデル | 1.1050 | 0.1169 |

MASEは予測した期間の平均絶対誤差を、同じ系列の学習期間に「1季節前の値をそのまま使う方法」で求めた平均絶対誤差で割った値です。1を超えても、同じ将来期間で季節ナイーブ法より悪かったという意味ではありません。表8は各データセットの値を同じ重みの幾何平均で集計します。系列の多いデータセットに、その系列数に応じた重みを付ける集計ではありません。

表9では、自動車部品で併用版が0.828、TiRexが0.916でした。時間単位の電力データでは併用版が1.010、TiRexが0.912で、逆にTiRexの誤差が小さくなりました。併用版は、表9に掲載した7モデルの中で22件中10件が最小でした。人工データだけの版との比較では22件中16件で併用版が改善しました。表8の勝率91.9%は、データセットごとのモデル間の計836組を数えた値で、系列の91.9%で勝ったという意味ではありません。

著者は36の比較モデルを同じ評価手順で実行しました。自モデルの追加学習では、評価データと値が重なる学習候補358,008系列を除きました。ただし、既存モデルの事前学習データには同じ除外を適用できず、変換などを経た重複まですべて除けたという結果でもありません。評価には電力・M4・計算資源なども含まれます。表8はLightGBMなどの木モデルや、店舗の販促・価格などを特徴量にしたモデルとの比較ではありません。

## 図で確かめること

Labは5つの乱数の初期値で4種類の人工需要を生成します。各初期値につき検証用160系列の平均絶対誤差が最も小さい手法を、SES・Croston・SBA・TSBの中から全系列共通の手法として選びます。別に作った評価用320系列では、最初の150期間から次の30期間を予測します。評価には、両方式で同じ履歴と、1期前の値を基準とする同じMASE分母を使います。

混合方式には、SmoothにSES、IntermittentにSBA、ErraticにCroston、LumpyにTSBを当てます。Labが説明用に決めた対応であり、論文が学習した配分ではありません。式5・6のπを重みとして予測値を平均します。需要が発生するかはベルヌーイ分布で抽選し、発生したときの数量はガンマ分布から引いて丸めます。著者の負の二項分布を使う生成器とは別です。

需要分類の図ではADIとCV²を動かしてπとπ̃を比べられます。在庫の図では販促を固定したまま補充後の在庫目標を変えると、潜在需要は同じでも販売数が変わります。販促の有無を変えた場合は、潜在需要も変わります。どちらの操作も、古典手法の予測誤差を再計算するものではありません。

## Labの人工例

評価用データでは、5つの乱数の初期値のうち4つで、混合方式のMASEが検証で選んだ共通手法より大きくなりました。初期値19だけは0.8848から0.8702に下がりました。5回を同じ重みで平均すると、共通手法は0.85837、混合方式は0.85897です。需要の種類別の平均で改善したのはSmoothだけでした。学習用の比率を滑らかに変えられることと、この仮の対応で予測誤差が安定して下がることは別です。

在庫の図で販促を入れると、30期間の潜在需要は246個で共通です。補充後の在庫目標を10・40・100個に変えると、販売数はそれぞれ100・185・211個、売り逃した数は146・61・35個です。目標を100個にしても、在庫が8個を下回ってから入荷まで3期間かかる設定では、売り逃しは残ります。売り逃した需要は次の期へ持ち越しません。

## 確認したこと

Labは式5・6の4成分が合計1になり、2つの分類境界が重なる点では4成分が各25%になることを確かめました。入力の数量を10倍しても、ADIとCV²は変わりませんでした。古典予測器の混合は実行しましたが、学習済みの配分器やLoRAの補正は実装していません。

## 確認していないこと

Labは公開モデルでの推論、22データセットの評価、8 GPUでの学習を再現していません。在庫費用・サービス率・利益に対する効果も検証していません。著者は潜在需要・販売数・欠品フラグを分けて人工データを作りましたが、実店舗の販売記録から欠品中の潜在需要を復元することは、原論文でも将来の課題です。公開モデルには、販促・価格・祝日を別の入力として渡せません。それらの影響は履歴の値を通じてしか伝わりません。

## 手元での再現

配布ファイルを同じフォルダーに置き、標準ライブラリだけで `python run.py` を実行できます。結果は隣の `results.json` へ保存します。`stats()` は相対しきい値でゼロに近い値を扱い、式1・2のADIとCV²を求めます。`membership()` は式5・6の比率を求め、温度を指定すると式10の変換を加えます。`forecasts()` は4つの古典手法の予測値を返します。公表値22行は `run.py` に転記しており、実行しても著者のモデルを評価し直すことはありません。
