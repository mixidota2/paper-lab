# 原論文と配布資料の対応

| 原論文の箇所 | Labのどこを読むか | Labで扱う範囲 |
| --- | --- | --- |
| §1.1・定理1.1 | `method.md`、`evidence.md` | 固定納期と未納の繰り越しを前提に、発注時に同じ情報を使う最適方策（OPT）と何を比べるかを説明します。証明全体は再検証していません。 |
| §2.1〜2.2・補題2.1 | `run.py` の `Tree.probability_below()`、`charges()`、`simulate()` | 有限の需要木から、1個ずつ条件付きの保管費と未納費を求め、実際に発生する費用の期待値と照合します。 |
| §3.1〜3.2・§4.1 | `clocks()`、`simulate()`、`cdf()` | 当時の費用比率を残します。累計が共通閾値と等しい場合も発注に含めます。`recomputed`は過去まで計算し直す比較用で、論文の方策とは異なります。 |
| §4.1〜4.2 | `run.py` の全単位の列挙 | 小さい問題なので、すべての単位を調べます。論文の二分探索や確率への問い合わせ回数は再現していません。 |
| §4.3 | `tight()`、画面下の1期間の例 | 論文の式にεを代入します。小さなεでの値を見せますが、極限を証明するものではありません。 |
| Lab独自の最適費用 | `optimum()` | 有限の需要木に対し、各履歴で選べる発注数を調べて最小の期待費用を求めます。同じ履歴から分岐する経路では、将来の実現値にかかわらず同じ発注数を使います。 |
| Lab独自の画面 | `interactive.html`、`interactive.js`、`paper_lab/inventory_ct.py` | Pythonの計算済み結果を表示します。選択の切り替えとJavaScriptなしの初期表を自動検査しました。手動の実機操作は確認していません。 |
