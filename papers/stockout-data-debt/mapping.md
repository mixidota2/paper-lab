# 原論文と教材の対応

| 原論文 | 教材で確かめること | 確認していないこと |
| --- | --- | --- |
| 図1・第1節 | 観測割合20%・20%・60%を固定し、Γを変えた場合の需要確率と費用差を計算しました。 | 図の観測割合は論文の仮定です。実店舗から推定していません。 |
| 第3.2節 | 需要が0か1の例で、需要が分かる記録と分からない記録の構成差をオッズ比の上限Γで制限しました。 | 一般の需要分布に対する識別の証明は再検証していません。 |
| 式15 | 需要分布の候補ごとに最適な行動との差を計算し、差が最も大きい場合を比べました。 | 候補や行動が多いときの最適化は扱いません。 |
| 命題7・図2 | 在庫を翌日に持ち越す条件で、四つの決定的な発注ルールを計算しました。差の最大値を最も小さくできたルールの値は0.1225でした。 | 実際の在庫や発注にはつないでいません。 |
| 第5節 | この記事で信頼集合の役割を説明します。 | 有限の標本から作る保証は実装していません。 |
| 第6節 | 記事で、著者が人工例と加工した実販売資料を用いたことを説明します。 | 著者のコードと実験条件全体は再実行していません。 |

教材で使った確率や費用は、論文が人工例に置いた値です。計算が論文と一致しても、実店舗で費用が減ることは分かりません。[原論文の初版](https://arxiv.org/html/2611.19323v1)
