# 欠品した販売履歴から発注をどこまで決められるか

Chen・Jin・Qinの論文『The Data Debt of Stockouts』が示した人工例を計算する教材です。店の販売数だけでは分からない需要が、発注の判断をどう変えるかを調べます。著者の実店舗での効果を再現したものではありません。

ブラウザーの操作ではΓを切り替えます。需要を観測できた集団と隠れた集団の違いを大きく認めるほど、候補の需要分布が広がります。表示する棒は需要分布を知る最適行動に比べた最大の費用差です。売上、利益、信頼区間は表示していません。

## 再計算する

このフォルダーで次のコマンドを実行します。Pythonの標準ライブラリだけを使い、結果を同じフォルダーの results.json に保存します。計算は有理数で行い、JSONに保存するときだけ小数に変換します。

```sh
uv run --no-project python run.py
```

図1のΓ=11では、需要0の確率が0.25〜0.75、どちらの行動でも最大費用差が0.25になります。命題7の2期間例では全ての実行可能な決定的ルールを列挙し、最小の最大費用差0.1225を計算します。

## 読む順序

method.mdは仮定と数式を説明し、mapping.mdは原論文との対応を示します。run.pyが計算し、results.jsonが画面に渡す数値を保持します。lab.yamlには記事本文を含む構成が入っています。

本教材は有限標本の信頼集合、実店舗での費用、需要分布の変化、大規模な最適化を検証していません。Γの妥当性もデータから推定していません。
