# 同じ販売記録でも、最適な発注は変わる

売り切れた日は、買いたかった人が何人いたかを販売数だけでは確かめられません。この教材では、Chen・Jin・Qinの論文『The Data Debt of Stockouts』にある人工例を使い、見えなかった需要をどう仮定するかで発注の判断が変わることを確かめます。

## 画面で比べる

Γを大きくすると、需要が分かる日と分からない日で、需要の中身がより大きく違っていてもよいと仮定します。画面には、発注しない場合と1個発注する場合の棒が出ます。どちらも、その行動にとって最も不利な需要分布で、分布を知って選ぶ最適な行動よりいくら余分にかかるかを示します。二つの棒を計算する分布は同じとは限りません。費用は論文の例に置いた単位で、円ではありません。

## 手元で計算する

このフォルダーで次のコマンドを実行します。Pythonの標準ライブラリだけを使い、途中まで有理数で計算します。最後に小数へ変えて、同じフォルダーの `results.json` に保存します。

```sh
uv run --no-project python run.py
```

図1のΓ=11では、需要が0となる確率の候補は0.25〜0.75です。どちらの行動を選んでも、最も不利な場合は最適な行動より0.25多くかかります。命題7の2期間の例では、最初に1個買って補充しないルールを選ぶと、最も不利な場合の差を0.1225に抑えられます。

`method.md` に式と判断が分かれる理由、`mapping.md` に論文と教材の対応を書いています。`lab.yaml` は記事本文、`run.py` は計算、`results.json` は結果です。

この教材は二つの人工例だけを計算します。著者が扱う有限標本の保証、Γの推定、大規模な発注計画や実店舗での効果は確かめていません。[原論文の初版](https://arxiv.org/html/2611.19323v1)
