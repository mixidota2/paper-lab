# 出力の意味を在庫管理に合わせる

Iは手元と輸送中の在庫状態、xは外生特徴、tot(I)は総在庫。f=feat(x)には4つの過去・予測需要と定数1を含む。μは状態に依存する学習済みネットワークである。

```text
None:  q = μNone(I, x)
Base:  q = max(μBase(I, x) − tot(I), 0)
Coeff: q = μCoeff(I, x)ᵀ f
Both:  q = max(μBoth(I, x)ᵀ f − tot(I), 0)
```

原論文の導入部pp.3–4の式。Coeffの式に独自の切り上げやクリップを加えていない。実験では非負の出力を使う。入力の動的特徴と在庫をSKU内で正規化し、Coeffで需要規模へ戻すため、販売規模をまたぐ単一方策の学習につながる。

例えば総在庫が18個あるとき、ネットワークの出力24を直接発注量と読むNoneは24個を発注する一方、目標在庫と読むBaseは24−18=6個を発注する。同じ24でも役割が違う。在庫が30個ならBaseの発注は0になる。これを任意のq個の発注へ戻すには、Baseの出力をq+30とすればよい。
