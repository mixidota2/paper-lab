# ネットワークの出力から発注量を計算する4つの方法

手元と入荷予定の在庫が合わせて18個あり、ネットワークが24を出したとします。Noneは24を発注量として扱うので24個を発注します。Baseは24を目標在庫として扱うので、足りない6個だけを発注します。総在庫が30個なら、同じ目標では追加発注はありません。

式では、在庫の状態を `I`、それ以外の特徴を `x` と書きます。`tot(I)` は手元の在庫と入荷予定の合計です。ネットワーク `μ` は `I` と `x` を入力に取り、方式に応じて数を1つ、または係数を複数返します。計算後の発注量が `q` です。

```text
None:  q = μNone(I, x)
Base:  q = max(μBase(I, x) − tot(I), 0)
Coeff: q = μCoeff(I, x)ᵀ f
Both:  q = max(μBoth(I, x)ᵀ f − tot(I), 0)
```

CoeffとBothは、過去の短期・長期需要、予測した短期・長期需要、定数1を並べた `f=feat(x)` を使います。モデルが返した係数を順に掛けて足し、Coeffはその合計を発注量に、Bothは目標在庫にします。原論文の導入部pp.3–4に沿い、LabはCoeffに切り上げや下限を追加していません。図と逆算の実験では、発注量が負にならない出力を使っています。

著者は入力を正規化して、販売規模の異なる商品で同じ発注モデルを使います。Coeffを使う計算では、正規化した入力から求めた係数を需要特徴に掛け、発注量を商品の需要規模に合わせます。Labは発注量を計算する式だけを実装しており、正規化やネットワークの学習は含みません。
