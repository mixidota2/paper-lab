# 報告の受領日が違うと、同じ日の在庫が変わる

2日目に入荷した商品でも、倉庫からの報告が4日目に届くなら、2日目までの情報では使えません。このLabでは、一つの商品について5件の報告と3件の将来予定を使い、同じ3日目の在庫を再計算します。受領の締切を変えると、使う報告の版、在庫、売り逃しがどう変わるかを確認できます。

## 結果を自分で計算する

`run.py` を作業用フォルダへコピーし、そこで `python run.py` を実行します。Pythonの標準ライブラリだけを使い、実行したファイルと同じ場所に `results.json` を作ります。`cases` には、締切ごとに採用した報告、過去と将来の在庫の推移、五つの答えが入ります。

- [method.md](method.md)では、報告を選ぶ順序と、コードをモデルの前後に置く違いを説明します。
- [experiment.md](experiment.md)では、五つの報告と同じ将来予定から、三つの締切の結果を確認できます。
- [mapping.md](mapping.md)では、論文とLabの実験の違いを確認できます。

Labは決めた数量から在庫を計算するだけで、需要の予測やLLMの再評価は行いません。[著者論文v1](https://arxiv.org/html/2611.14671v1)は、モデルが報告の選択、過去の再計算、将来の計算のどこで間違うかを比べています。
