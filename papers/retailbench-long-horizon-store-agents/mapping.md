# 原論文・公式コードとの対応

一次資料は[arXiv:2603.16453v3](https://arxiv.org/pdf/2603.16453v3)（2026年7月8日）。2606.15862を別研究として数えない。

| 原論文 | Labの対応 | 省略・境界 |
|---|---|---|
| Figure 1、§2.3：7モジュール | 店舗の結合図 | ニュース、返品、在庫、棚、資金のつながりを説明用に再配置 |
| §3.1：96商品、20カテゴリ、180日 | lab.yamlの問題設定 | 人工実験の商品数とは別 |
| Table 1、§4.1：生存優先の実行選択 | results.jsonのreported、モデル比較パネル | 全試行平均や同一情報条件の比較ではない |
| §4.3、Figure 3 | 3種の診断表 | 失敗要因ごとの因果効果は未検証 |
| §3.3：純資産・販売数量 | 著者報告の棒グラフ | 販売数量は金額ではない |
| 仕入先品質・返品・資金の結合 | run.pyのsimulate() | 人工定数の即時補充。公式の需要式や遷移を再実装していない |

[公式コード](https://github.com/linghuazhang01/RetailBench)は論文末尾で案内されるリポジトリ。今回、コードの取得・実行・ファイル単位の対応確認は行っていない。

純資産の説明には原文内の差がある。§3.3は現金・手持在庫・未着発注の価値を含むと述べるが、付録の式(18)は現金と年齢別手持在庫を明示している。Labはこの差を解消したとは扱わず、Table 1の報告値を転記する。人工実験は現金だけを表示し、純資産と呼ばない。
