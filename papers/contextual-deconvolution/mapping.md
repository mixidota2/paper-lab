# 論文と教材の対応

著者は実データから販売数を予測し、補充にかかる日数を含めて発注後の費用を計算しました。Labの図では、すでに決めた二つの在庫の置き方に同じ需要を当てはめ、保管費と欠品費だけを比べます。

| 論文で確かめる箇所 | 著者の比較 | Labでの扱い |
|---|---|---|
| §4.4のFinding 4b（p. 13）と図2（p. 14） | M5の1,000商品について商品ごとの平均日次費用を出し、その中央値を比較しています。欠品単価は10ドル。費用が逆転する境界は約0.20で、ブートストラップによる95%区間は0.17〜0.25でした。 | この境界をFavoritaへ当てはめません。教材の費用は (48r+4) と (12r+36) で、等しくなるのは (r=8/9) です。 |
| 表3（p. 10） | 著者は費用の境界を調べた対象を100 SKUと書いています。 | 本文と図2の1,000商品とは件数が一致しません。どちらが正しいかは判断していません。 |
| 付録R.6の表15（pp. 36–37） | 著者は同じ100商品に両手法を使い、28日間の費用を足しました。 | 28日分を足した値と、図2で比べた平均日次費用の中央値は別の値です。 |
| 付録U（p. 39） | 著者は予測の分散を実績の分散で割ると定義した直後に負の値を説明しています。 | 定義と説明が一致しません。分散の比と、その比から1を引いた値を同じ指標として扱いません。 |
