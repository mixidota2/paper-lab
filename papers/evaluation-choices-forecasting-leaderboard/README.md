# 同じ予測でも評価単位を変えると順位が変わる

## 概要

著者は、同じ取引市場のデータを使い、市場全体の流通取引額を予測する場合と、買い手ごとに予測する場合で、手法の評価がどう変わるかを調べました。本番の基準手法は市場全体で19手法中2位でしたが、買い手別では25手法中23位でした。

この比較では評価に使った手法数や予測の起点、誤差指標も異なります。著者が手法と起点をそろえて比べ直しても、基準手法は市場全体で19手法中2位、買い手別で17位でした。市場全体では買い手ごとの増減が打ち消し合うことがあり、全体でよく当たる方法が各買い手にも適しているとは限りません。

## 問題設定

著者はField Nationで、買い手が依頼し技術者が完了した仕事の月間流通取引額（GTV）を予測しました。対象は仕事の取引額で、運営会社の売上や商品の個数ではありません。市場全体の取引額は滑らかに見えても、買い手別では取引がない月が挟まります。

データは2021年1月から2026年7月までの67か月、買い手5,779の事業者分です。本番システムは取引履歴が13か月未満の買い手には予測を出しません。少なくとも1つの起点で評価対象になった買い手は1,887の事業者で、条件を満たさない買い手の予測や誤差は評価していません。

本番の基準手法は前年同月の値を直近の伸びで調整します。予測誤差を尺度の違う系列で比べるために使う、伸びを調整しない季節ナイーブ法とは別です。買い手別の主評価では予測を始める時点を3か月ずつずらし、8起点・11,516ブロックで各起点から先の6か月を採点しました。事業で使う予測は12か月先までですが、手法を選ぶ際の評価幅は6か月です。

## 評価の設計

著者は、どの単位で誤差を数え、どの指標と手法を使うかによって、同じ市場でも予測の評価が変わると報告しました。比較手法と予測の起点をそろえても、順位の差は残りました。

Labでは、予測の優劣を比べる前に、予測をどう使うかを決めます。全体の売上計画に使う予測と、店舗・商品ごとの補充に使う予測とでは、誤差を数える単位が異なります。

## 誤差を数える単位と手法の選び方

### 1社ずつの誤差と、組にまとめた誤差

人工例の4社の実績は100ずつです。予測Aから実績を引くと、差は順に +40、−40、+40、−40 です。予測Bでは各社が +10 です。全体を1組にして差を足すと、Aは0、Bは40です。合計の絶対値を実績の合計400で割るので、WAPEはAが0%、Bが10%です。先に1社ずつ絶対値を取ると、Aの分子は160になり、WAPEは40%に上がります。Bの分子は40のままです。

同じ組をさらに細かく分けても、各組の絶対値の合計は小さくなりません。三角不等式 |Σeᵢ| ≤ Σ|eᵢ| が成り立ち、実績の合計は変わらないためです。ただし、別の組分けに入れ替えればWAPEは上下します。2組でも、過大予測と過小予測を一緒にすればAが0%、同じ方向の誤差をまとめればAが40%になります。各手法の誤差が分割で下がらなくても、どちらの手法が上位になるかは決まりません。

### 論文で比較条件をそろえる方法

表1には集計単位だけでなく、指標・起点・手法数の違いもあります。そのため図1と表3では、共通する19手法を使い、評価より前の取引規模に基づいて買い手を組に分けます。組数1・5・25・125・625に対し、WAPEの中央値で並べた本番の基準手法の順位は2・14・14・16・16位でした。滑らかな需要の系列の割合は100%から27%へ減りましたが、組を増やすたびに順位が下がったわけではありません。表1の買い手別23位は25手法での順位なので、この比較の点としては扱いません。

### 予測区間を同じ作り方で比べる方法

著者は各手法の点予測の誤差に同じ分割コンフォーマル法を適用して、予測区間を作りました。区間の指標は、区間が広いほど、また実績が区間の外に離れるほど大きくなります。実績が区間に入った割合（被覆率）も別に見ます。表5は193,067レコードを対象とし、25手法の順位を比較します。間欠需要の順位相関0.02はこの条件での推定値です。

### 過去の誤差から次に使う手法を選ぶ方法

著者は買い手ごとに、今より前の評価起点が3つ以上ある場合に手法選択を試しました。過去の評価の半分以上で結果があり、平均の符号付き誤差を尺度で割った値が所定の範囲に入る手法を候補に残します。候補を平均RMSSEで並べ、上位3手法の予測を平均します。RMSSEは、予測期間の平均二乗誤差を、過去の期間に季節ナイーブ法を使ったときの平均二乗誤差で割り、その平方根を取った値です。

表6は、その手順が基準手法から改善できる幅をどれだけ埋めたかを、G = (E_baseline − E_served) / (E_baseline − E_oracle) で測ります。著者の報告は54.6%です。表の丸め済みの0.946、0.724、0.540だけで計算し直すと約54.68%になります。ここでいうoracleは、結果が出てから評価ブロックごとに最良の単独手法を選ぶものです。予測時には使えず、事後に複数手法の平均まで選べる比較に変えれば、回収率はさらに小さくなりえます。

著者は§11で、以前はアンサンブルのRMSSEを計算する際、分母にMAEを使っていたと報告しました。その誤りを直すと、アンサンブルが悪化させると見えていた結論が逆転しました。Labの人工例で起きたWAPEの逆転とは別の話です。

## 予測の使い道で評価が変わる理由

ある会社への過大予測と別の会社への過小予測は、符号付きで合計してから絶対値を取ると打ち消し合います。1社ずつ絶対値を取れば、どちらの誤差も残ります。予測自体が同じでも、どこで合計するかによってWAPEは変わります。

著者は、時系列基盤モデル（TSFM）や決定木の勾配ブースティング（GBDT）を含む手法を比べました。ただし、点予測の順位は一つの値がどれだけ当たるかで決まります。区間予測では、区間の幅と、実績値が範囲に入る割合も見るので、点予測の順位だけでは区間の良さは分かりません。

## 論文の比較結果

[一次資料（原論文v1）の表1・3・5〜8](https://arxiv.org/html/2609.27867v1)では、市場全体で19手法中2位、買い手別で25手法中23位でした。表1は、全体では22起点の平均WAPE、買い手別では8起点の平均RMSSEを使っています。集計だけを変えた比較ではありません。共通の19手法と8起点にそろえた比較では、全体2位、買い手別17位でした。全体をRMSSEで並べ直すと2位から1位になり、買い手別の誤差を取引規模で重み付けすると23位から20位になりました。

表3では、起点と手法をそろえたまま、評価前の取引規模で買い手を1・5・25・125・625組に分けました。WAPEの中央値で並べた本番の基準手法の順位は順に2・14・14・16・16位です。平均RMSSEの順位は5・14・14・17・17位で、指標によって順位は異なります。組を同じ数だけ無作為に作っても、WAPE順位は2・6・10・15・16位でした。どう分けるかで順位は変わりますが、細かい単位で評価すると下がる傾向は残りました。

手法間で誤差の差を調べる検定は順位とは別です。著者の検定で本番の基準手法を有意に上回った手法は、市場全体で0、買い手別で19でした。予測期間が重なり同じ月が複数回入るため、著者は25か月の月単位でも比較し、このデータでは19手法が有意に上回る結果が残りました。買い手別の平均RMSSEでは基準より上位だったLightGBMと季節トレンドは、各期の誤差をまとめた検定では、逆に基準手法のほうが良いと判定されました。別の市場でも同じ検定結果になるという意味ではありません。

表5では、25手法で点予測と区間予測の順位を比べました。全体の順位相関は0.39（p=0.0509）、間欠需要は0.02（p=0.9099）でした。この比較から、あらゆる間欠需要で両者に関係がないとは言えません。本番手法の名目95%の予測区間に実績が入った割合は、滑らかな需要で92.5%、間欠需要で74.1%、発生間隔も金額のばらつきも大きい需要で74.2%でした。どのモデルにも同じ方法で区間を作った比較で、モデルがもともと出す分位点の比較ではありません。

表6の手法選択を使うと、対象5,832ブロックで、RMSSEは本番の基準手法の0.946から0.724へ23.5%下がりました。結果が出てから各ブロックの最良手法を選ぶ比較値は0.540で、著者は改善できる幅の54.6%を埋めたと報告しました。一方、DeepARを使い、予測できないときだけ基準手法に戻すと約52%、すべての対象を予測できる最良の単独手法では約54%を埋めました。このデータでは、強い単独手法との差は小さくなります。

公開小売データM5では、ウォルマートの10店舗の日次販売数を63か月に集計しました。店舗×商品の30,490系列のうち、30,449系列を評価できました。表7の7手法では、基準手法は市場全体と店舗別で1位、店舗×商品では7位でした。同じブロックを比べられる範囲で手法選択を試すと、改善できる幅の64.7%を埋めました。表8では事前学習済みモデルを加えた12手法で、基準手法は市場全体2位、店舗別4位、店舗×商品で12位です。市場全体と店舗別の首位はFlowState、店舗×商品の首位は減衰を使う平滑法でした。著者が月次に集計して比べ直した結果であり、M5コンペの順位ではありません。公開M5を既存モデルが事前学習で見ていた可能性も残ります。M5の点予測と区間予測の順位相関は、事前学習済みの5手法を加えても全体で0.89のままでした。Field Nationとの差を、手法の種類だけで説明することはできません。M5の基準手法では、名目95%の区間の被覆率は滑らかな需要で86%、間欠需要で79%、発生間隔も数量のばらつきも大きい需要で68%でした。

## Labの人工例

4社を1組にすると、WAPEはAが0%、Bが10%です。4社を個別に測るとAが40%、Bが10%になり、誤差の小さい予測が入れ替わります。2組でも、Aの過大予測と過小予測を組に1社ずつ入れるとAが0%、同じ向きの誤差をまとめるとAが40%です。Bはどの場合も10%です。

4社を分ける15通りをすべて比べると、Aは3通り、Bは12通りで誤差が小さくなります。組の数が同じでも、誰を同じ組にするかで結果が変わります。これは組分けの数の比較で、実際にAが勝つ確率を表す数字ではありません。

## 確認したこと

Labは4社の人工例で、同じ実績と予測のまま組分けを変えると、WAPEで評価した順位が逆転することを確認しました。表6の表示値から回収率を計算し直したのは、式の意味を確認するためです。著者のデータや方法で選択手順を追試したものではありません。

## 確認していないこと

LabはField Nationの非公開データ、M5の全手法、予測区間の生成と統計検定を再現していません。データを大きくしたときの処理性能や、本番での効果も確かめていません。この比較では、店舗の補充費用を最も下げる手法や、企業の利益への効果は分かりません。

## 手元での再現

配布の `run.py` は標準ライブラリだけで動きます。`python run.py` を実行すると、4条件のWAPEと各条件で誤差が小さい手法を計算し、隣の `results.json` に保存します。`gap_closed_from_rounded_table6` は表6の丸め済みの値だけから回収率を計算した項目です。操作図はこのJSONに保存した4条件を切り替えます。
