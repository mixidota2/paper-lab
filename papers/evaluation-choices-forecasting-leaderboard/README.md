# 同じ予測でも、誰をひとまとめにするかで順位は変わる

ある買い手の取引額を40多く、別の買い手を40少なく予測しても、合計はぴったり合う。市場全体の予測が合っていることと、買い手ごとの予測が合っていることは別だ。

論文では、サービス市場の本番基準手法が市場全体で19手法中2位、買い手別で25手法中23位だった（表1）。ただし、ここでは評価指標、予測を始める時点、比較手法数も違う。集計の影響を読むなら、19手法を共通にした表3も見る。全買い手を1組とした評価で2位だった基準手法は、625組に分けると16位になった。

[Labを開く](https://mixidota2.github.io/paper-lab/papers/evaluation-choices-forecasting-leaderboard.html)

## 評価の単位は、予測で行う判断に合わせる

著者が扱ったのは取引の総額（GTV）で、店舗小売の売上ではない。著者は小売の公開データM5でも、店舗と商品の組み合わせごとに評価をやり直した。Labでは、時系列基盤モデル（TSFM）と勾配ブースティングで作る決定木モデル（GBDT）を比べる前に、全体予算用なのか、店舗・商品ごとの補充用なのかを決める、という教訓を読み取った。店舗の補充費用を最も下げる手法を示した研究ではない。

[手法の説明](method.md)で集計を変えたときの順位と、指標が違う比較を読む。[原論文との対応](mapping.md)には、各図・人工例が何を説明し、何を再現していないかをまとめた。

## 4人の買い手で集計順を試す

```sh
uv run papers/evaluation-choices-forecasting-leaderboard/run.py
uv run paper-lab build
```

最初のコマンドはPythonの標準ライブラリだけで動き、同じフォルダーの `results.json` を更新する。4人の実績と予測A・Bはそのままにして、誰を一組にまとめるかを変える。各組の誤差を符号付きで合計してから絶対値を取り、全組の絶対値を足して実績総額で割る（WAPE）。市場を1組とするとAが0%、Bが10%。買い手ごとに測るとAが40%、Bが10%となり、誤差が小さい予測が入れ替わる。2組でも、組む相手によって結論が変わる。

人工例でこの逆転を確認した（CONFIRMED）。仕組みの確認はこの範囲に限り（PARTIAL）、本番データ、モデルの学習、手法選択の性能、区間予測、統計検定は再現していない。本番での効果や、大規模に運用できるかも未検証（NOT TESTED）。
