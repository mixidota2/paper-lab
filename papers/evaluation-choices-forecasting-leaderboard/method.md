# 誤差を数える単位と手法の選び方

## 1社ずつの誤差と、組にまとめた誤差

人工例の4社の実績は100ずつです。予測Aから実績を引くと、差は順に +40、−40、+40、−40 です。予測Bでは各社が +10 です。全体を1組にして差を足すと、Aは0、Bは40です。合計の絶対値を実績の合計400で割るので、WAPEはAが0%、Bが10%です。先に1社ずつ絶対値を取ると、Aの分子は160になり、WAPEは40%に上がります。Bの分子は40のままです。

同じ組をさらに細かく分けても、各組の絶対値の合計は小さくなりません。三角不等式 |Σeᵢ| ≤ Σ|eᵢ| が成り立ち、実績の合計は変わらないためです。ただし、別の組分けに入れ替えればWAPEは上下します。2組でも、過大予測と過小予測を一緒にすればAが0%、同じ方向の誤差をまとめればAが40%になります。各手法の誤差が分割で下がらなくても、どちらの手法が上位になるかは決まりません。

## 過去の誤差から次に使う手法を選ぶ方法

著者は買い手ごとに、今より前の評価起点が3つ以上ある場合に手法選択を試しました。過去の評価の半分以上で結果があり、平均の符号付き誤差を尺度で割った値が所定の範囲に入る手法を候補に残します。候補を平均RMSSEで並べ、上位3手法の予測を平均します。RMSSEは、予測期間の平均二乗誤差を、過去の期間に季節ナイーブ法を使ったときの平均二乗誤差で割り、その平方根を取った値です。

表6は、その手順が基準手法から改善できる幅をどれだけ埋めたかを、G = (E_baseline − E_served) / (E_baseline − E_oracle) で測ります。著者の報告は54.6%です。表の丸め済みの0.946、0.724、0.540だけで計算し直すと約54.68%になります。ここでいうoracleは、結果が出てから評価ブロックごとに最良の単独手法を選ぶものです。予測時には使えず、事後に複数手法の平均まで選べる比較に変えれば、回収率はさらに小さくなりえます。
