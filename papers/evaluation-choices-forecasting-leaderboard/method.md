## 誤差を足す順番を変える

Table 3とFigure 1が評価粒度の中心図。集計数kを増やすと平滑な市場系列から変動の大きい小集団へ移る。表の中央値WAPE順位はk = 1, 5, 25, 125, 625で2, 14, 14, 16, 16位。これは19手法内の順位であり、25手法による買い手別順位を同じ曲線へ継ぎ足さない。

人工例は4買い手すべての実績を100とする。Aの誤差は+40, −40, +40, −40、Bはすべて+10。市場全体ならAの誤差は相殺され0%、個別に絶対誤差を足すと40%。Bはどちらも10%となる。同じ2組でも分け方によってAの相殺の有無が変わる。

Table 6の回収率はG = (E_baseline − E_served) / (E_baseline − E_oracle)。表示されたRMSSEの0.946、0.724、0.540からは約54.68%となる。論文の54.6%との差は、丸め済み値からの再計算として残す。oracleは事後に最良手法を選ぶ上限で、本番で実装できる選択器ではない。

区間予測のTable 5は193,067レコードを評価する。間欠需要での相関0.02は、25手法間の限られた推定である。全需要・全期間で点予測と区間予測が独立だと証明した数値ではない。
