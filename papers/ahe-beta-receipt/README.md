# 成果物の検査と、利用者が受け取った結果を分ける

[Agentic Harness Engineering Beta](https://arxiv.org/html/2611.24924v1)をもとにした教材です。架空の集計レポートを例に、成果物の検査に合格しただけで作業完了と数える場合と、現行版の受け取りも求める場合を比べます。要件の根拠を確認し、変更案とレビュー対象の版が同じかを確かめる条件も別に試します。

```bash
uv run --locked papers/ahe-beta-receipt/run.py
```

標準ライブラリだけを使い、同じ場所の `results.json` に全48通りの集計と、画面で試せる7通りのデータを書き出します。操作図の数値は0または1で、論文の成功率ではありません。論文の更新手順すべてや、LLMによる作業は実行しません。モデルの性能、費用、運用への適用は未検証です。
