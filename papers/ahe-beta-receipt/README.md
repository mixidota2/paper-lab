# 成果物の検査と、利用者が受け取った結果を分ける

エージェントが正しい集計レポートを作っても、利用者がそのレポートを受け取ったかは別の問題です。[Agentic Harness Engineering Beta](https://arxiv.org/html/2611.24924v1)をもとにしたこの教材では、架空の集計レポートを使い、検査の合格だけを数える場合と、現行版の受け取りも確かめる場合を比べます。

作業が完了したかという判定と、仕組みへの変更を採用できるかという判定も分けます。後者では、要件の根拠を確かめたうえで、実際に採用する変更案とレビューされた版が同じかを確認します。

```bash
uv run --locked papers/ahe-beta-receipt/run.py
```

スクリプトはPythonの標準ライブラリだけを使います。全48通りの集計と、画面で選べる7通りのデータを同じフォルダーの `results.json` に書き出します。画面は条件を満たした例に1を表示します。条件を満たさない場合や、確認に必要な記録がない場合には0を表示します。この数値は論文の合格率ではありません。

この教材では、論文の開発手順を動かしたり、LLMに実際の作業をさせたりしません。モデルの性能や費用、実運用への適用は検証していません。
