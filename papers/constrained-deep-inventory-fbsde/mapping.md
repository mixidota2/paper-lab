# 原論文とLabの実装の対応

一次資料は[原論文v1](https://arxiv.org/html/2609.11817v1)です。PDFでは公式コードへのリンクを確認できませんでした。Labは著者の実装を実行せず、式の一部を別のコードで計算しました。

| 原論文 | Labで読む場所 | Labで再現していないこと |
| --- | --- | --- |
| 式(1)・(2)、§III | `run.py` の `derivative_check` で、発注率の影響が輸送中在庫には1回、手元在庫には2回の微分で現れることを計算します。 | 雑音、流量の飽和、複数商品。 |
| 式(9)・(15) | 図の各条件で、輸送中在庫と手元在庫から決まる発注率の上限を示します。 | 非線形な流量の導関数、拡散補正、排出枠の重み。 |
| 式(11)、定理3・5 | 図で現在の空きと h₁ を表示し、二次計画に解があるか、連続時間の定理の初期条件を満たすかを区別します。 | 各時点の制約を満たし続ける制御、切り替え後の経路の保証。 |
| 式(20)、§IV-C | 上限を緩めない例で、調整前の発注率4に最も近い値を選びます。 | 学習した価値の勾配、集計枠や発注上限の緩和、CLARABEL。 |
| 図1〜3、表II〜IV | 本文で、充足率・違反率・超過量と、別の100商品比較を説明します。 | 著者が実行した需要経路と在庫推移の再計算。 |
| §IV | 手法の説明で、価値の勾配を発注計算に使う流れを示します。 | FBSDEのネットワーク、終端損失、学習。 |

図で使う調整前の発注率4は、上限が効く様子を見せるためにLabで設定した値です。論文が学習した値ではありません。共通の区間がないときは、上限を緩めない条件では発注率を選べないことを表示します。
