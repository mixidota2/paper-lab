# 棚割りの調査記録

[6事例のまとめ](shelf-allocation-evidence-2026-10-29.md)では、著者が何を予測し、店舗が何を変え、実施後にどんな効果を測ったかを分けて整理しました。同じ棚配分案について、利益を予測し、その案を実店舗で実施し、予測と実測利益を照合したところまで確認できた事例はありませんでした。

## 個別の研究を読む

- [Chu（2009）の日本語版](chu-2009-ja.md)：著者は香港のコンビニで集めたデータを使い、棚の割り当て案の粗利を見積もりました。この粗利は案を実施した後の実測値ではありません。[英語の調査記録](chu-2009.md)
- [Sachseほか（2023）の日本語版](display-variety-2023-ja.md)：著者はドイツの24店舗で値引きを伴う特設陳列を行い、販売数を比べました。配置を変えた場合の利益は、著者が後から試算した値です。[英語の調査記録](display-variety-2023.md)

日本語版は英語の調査記録をもとに作成しました。原著を読み直した結果ではありません。
