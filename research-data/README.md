## 数字と過去の結論の読み方

ここにある数字は、論文などの出典が報告した値か、各記録で独自の計算と明記した値です。原著の実験を独立に再現した結果ではありません。モデルやシミュレーションで見込んだ改善は、実店舗の実績と区別してください。観察データから差が見えても、施策が差を生んだとは限りません。論文の版、分母、指標、集計期間が異なる数字を一つの結果にまとめないでください。

日付とリンクは当時の記録を残しています。資料を移した際に、リンク、書誌項目、原著の実験をすべて確認し直したわけではありません。本文は評価せず、書誌情報だけ残した項目もあります。Exaへのリンク2件は資料を見つける手がかりで、原著の正式な公開先とは確認できていません。arXivにない棚割りの枠組みの文献には、DOIを記録し、arXiv IDは空欄にしています。

過去の検索で資料が見つからなかったという記録は、そのときに探した範囲での結果です。10月30日の調査で、10月29日に発表された資料をすべて見つけられたかは確認していません。古い記録を読むときは、次の追記と留保も確認してください。

- WRAPPED S2：初期の記録では未読でした。10月23日の追記のほうが新しい情報です。
- Proximal Residual の OOS：この記録では out-of-sample（学習などに使った標本の外）の略で、out-of-stock（欠品）ではありません。
- Spine：論文とリポジトリの数値がなぜ異なるかは確認していません。
- A Bitter Lesson：当時の調査で分かったことを記録したもので、現在の調査優先度や公開の判断を示してはいません。

## 収録していないもの

公開された学術資料へのリンクと、調査担当者が書いた要約・分析を収録しています。論文のPDF、第三者の記事全文、画像、モデルの重み、第三者のコードは含みません。原著の権利は各権利者に残ります。非公開の会話、個人の読書やコメントの記録、個人の好み、認証情報、ローカルのパス、自動化の指示、通知や運用のログも収録していません。
