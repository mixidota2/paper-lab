# Labの調査データと読書記録

Labの調査担当者が2026年9月〜11月に読んだ論文について、書誌情報や要約、調査の問い、出典をもとに考えたことを残しています。どの資料を読み、何を根拠に判断したかを知りたいときに使えます。検索手順を決めて文献を網羅したレビューではなく、公開時に書誌情報をすべて確認し直したわけでもありません。

## 数字と過去の結論の読み方

数字は、論文などの出典が報告した値か、調査担当者が独自に計算したと明記した値です。原著の実験を独立に再現した結果ではありません。モデルやシミュレーションが示す改善の見込みと、実店舗で記録された実績を分けて読んでください。観察したデータに差があっても、施策がその差を生んだとは限りません。複数の値を読むときは、どの版の論文か、何を分母にしたか、どの指標をいつ集計したかを確かめ、条件が異なる数字を一つの結果として扱わないでください。

日付とリンクは、調査した当時のまま残しています。資料を移したときに、すべてのリンクを開き直したり、書誌情報や原著の実験を確認し直したりはしていません。中には、本文を評価せず、論文名などの情報だけを残した項目もあります。Exaへのリンク2件は資料を探す手がかりですが、原著の正式な公開先かどうかは未確認です。arXivで公開されていない棚割りの枠組みを扱った文献には、DOI（文献の識別子）を記録し、arXiv IDは空欄にしています。

「資料が見つからなかった」という記録は、調査担当者が当時探した範囲での結果です。10月30日の調査で、10月29日に発表された資料をすべて見つけたかは確認していません。次の話題については、後から読んだ資料や、当時分からなかったこともあわせて確認してください。

- WRAPPED S2：最初の記録を作った時点では未読でした。その後に確認した内容は10月23日の追記にあります。
- ORPR（arXiv:2512.19001）：論文一覧の「A/B+DiD」は現場で比較する商品を無作為に割り付けたという意味ではありません。JD.comの担当者がORPRを使う商品を選び、著者は在庫回転などが似た商品を比較対象に選びました。また、表4の在庫あり日率は原論文では「Y+0.47%」と表記されています。一覧の「+0.47pp」は原論文が明示した単位ではありません。比較方法と数値の読み方は[現在のLab記事](https://mixidota2.github.io/paper-lab/papers/orpr-or-guided-pretrain-reinforce-inventory.html)で確認できます。
- Proximal Residual の OOS：この記録のOOSは、学習などに使った標本の外（out-of-sample）の略です。欠品（out-of-stock）の意味ではありません。
- Spine：論文とリポジトリで数値が違う理由は確認していません。
- A Bitter Lesson：当時の調査で分かったことを記録しました。今の調査でどれを優先するか、何を公開するかの判断は示していません。

## 収録していないもの

このフォルダーで提供するのは、公開された学術資料へのリンクと、調査担当者が書いた要約や分析です。論文のPDF、第三者の記事全文、画像、モデルの重み、第三者のコードは入っていません。原著の権利は各権利者に残ります。非公開の会話、個人の読書やコメントの記録、個人の好み、認証情報、ローカルのパス、自動化の指示、通知や運用のログも含めていません。
